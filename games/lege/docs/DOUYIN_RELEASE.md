```

  js/main.js            游戏代码 (与网页版同一套源码打包)
  assets/images/        卡牌、背景 (已压缩)，dark/ 预渲染的"被压住"暗色卡牌
  assets/sfx/           44 个预渲染音效 mp3
  assets/share.png      分享卡片图 (5:4)
  assets/audio/         ── 分包 "audio" ──  角色语音 + 背景音乐 mp3
```

包体（2026-10-11 构建，上限取自抖音分包文档：主包 ≤ 4 MB、单个分包 ≤ 20 MB、整包 ≤ 20 MB）：

| 部分 | 大小 | 上限 |
|---|---|---|
| 主包 | 约 0.98 MB | 4 MB |
| 分包 audio（语音 + BGM） | 约 2.87 MB | 20 MB |
| 整包 | 约 3.86 MB | 20 MB |

每次 `npm run build:douyin` 都会重新计算并写进 `build/douyin-size.json`，超限会直接报错。

## 1. 注册抖音开放平台，创建小游戏，拿到 AppID

1. 打开 <https://developer.open-douyin.com/>，用抖音账号登录，完成**开发者认证**。
   - 个人主体和企业主体能做的事情不一样（个人主体在类目、变现、版号相关能力上限制更多），**做商业化建议用企业主体**。
   - **认证主体名称 = 软著著作权人 = 隐私协议里的运营者名称**，三处必须一致（见第 6 节）。「狸猫」只是出品 / 品牌名，不能代替主体名称。
2. 控制台 → **创建应用** → 选择 **小游戏**，填写名称「美少女了个美」（名称需与软著一致，提交后改名要重新审核）。
3. 创建后在 **开发管理 → 开发设置**（不同版本控制台叫法略有不同）看到 **AppID**（以 `tt` 开头）。
4. 把 AppID 填进 `抖音小游戏/douyin.config.js`：

```js
appid: 'tt0123456789abcdef',          // ← 换成你的
```

5. 同一页面里的 **服务器域名** 不用配置：本游戏不联网（没有自己的服务器，存档只存在手机本地）。

## 2. 广告：首发版不带广告，上线后再开通流量主

**流量主（广告变现）要等小游戏上线后才能申请**，个人主体还要求 DAU ≥ 50（以平台页面为准）。所以 **v1 首发不带广告**，这件事只由 `douyin.config.js` 里的 **一个值** 决定：

```js
rewardedAdUnitId: '',   // ← 留空 = 首发版：没有任何广告
```

| `rewardedAdUnitId` | 卡槽塞满时 | 界面上 |
|---|---|---|
| `''`（留空，首发默认） | 弹窗「塞满了！再给你一次机会，帮你挪走 3 张」→ 按钮 **「再试一次」**，每关免费一次 | **不出现任何广告字样、广告画面或广告按钮**；玩法说明也写"塞满时可以再试一次" |
| 填了广告位 ID | 弹窗「看个广告，帮你挪走 3 张」→ **「看广告复活」** → 激励视频，看完才复活 | 自动切换，不用改代码 |

（可选的第二个开关 `freeReviveWithoutAd: false` = 没有广告位时干脆不提供复活。默认 `true`，一般不用动。）

**上线后开通广告的步骤：**

1. 开放平台控制台 → **变现**（或"流量主"）→ 申请开通（满足条件后）。
2. **广告管理 → 新建广告位** → 类型选 **激励视频**，名称写"复活"。
3. 复制 **广告位 ID**，填进 `douyin.config.js`：

```js
rewardedAdUnitId: '1234abcd5678efgh',   // ← 换成你的
```

4. 重新上传一个版本并提交审核。

填了 ID 之后的广告规则（已经实现，不用改）：

- 只在"卡槽塞满 → 看广告复活"时出现，玩家主动点才播放，**不会强制弹广告**，也没有插屏 / Banner。
- `onClose` 回调里 `isEnded === true` 才发奖励；中途关闭提示"广告没看完，复活不了"。
- 拉取失败 / 无填充（`onError`）提示"广告暂时加载不出来，稍后再试"，不发奖励（想失败也给奖励，把 `rewardOnAdError` 改成 `true`）。
- 广告播放期间 BGM、语音、音效全部暂停。

> 改完 `douyin.config.js`：用源码构建的运行 `npm run build:douyin`（构建日志会打印"复活方式：免费「再试一次」"或"复活方式：激励视频"）；直接用 `抖音小游戏` 文件夹的，改这个文件即可。`project.config.json` 里的 appid 在开发者工具导入时选择你的 AppID（工具会自动写回）。

## 3. 用开发者工具导入、预览、上传

1. 下载安装 **抖音开发者工具**（开放平台 → 文档 → 开发者工具，下载最新版）。
2. 打开工具 → **导入项目** → 目录选 `美少女了个美/抖音小游戏` → AppID 选你的小游戏（还没有 AppID 时可以先用工具提供的测试号看效果）。
3. 模拟器里应能看到：加载页（含健康游戏忠告、适龄提示、AI 生成内容说明）→ 菜单 → 开始游戏。
   - **模拟器不支持录屏**，录屏 / 分享录屏只能真机测。
   - 没填广告位（首发默认）时，卡槽塞满会出现「再试一次」，没有任何广告。
4. 工具栏 **预览** → 用抖音扫码，在真机上测试：
   - 点牌、三消、道具、卡槽塞满后「再试一次」（填了广告位后变成看广告复活）
   - 一局玩 3 秒以上 → 结算页「分享通关录屏」→ 跳到抖音视频发布页
   - 切到后台再回来：游戏暂停、声音停
   - 菜单左上角「侧边栏礼包」→「去侧边栏」→ 从抖音首页侧边栏重新进入 → 再点「侧边栏礼包」→「领取奖励」
5. 测试没问题 → 工具栏 **上传**，填版本号 `3.3.0` 和更新说明。
6. 回到开放平台 → 版本管理 → 把刚上传的版本 **提交审核**，审核通过后 **发布**。

## 4. 已接入的抖音能力（审核时会被问到）

| 能力 | API | 说明 |
|---|---|---|
| 画面 / 触摸 | `tt.createCanvas`、`tt.onTouchStart/Move/End/Cancel` | 直接用官方 API，没有 DOM 适配器；内容 9:16 居中，自动避开刘海、右上角胶囊和底部手势条 |
| 图片 | `tt.createImage` | |
| 声音 | `tt.createInnerAudioContext` | **全部 mp3，包里没有任何 .ogg**（iOS 抖音不能播 ogg；构建时会检查，出现 ogg 文件或引用直接报错）。BGM 3 首**无缝循环**（见下）、角色语音共用 1 个播放器、音效 6 个轮流播放（WebAudio 合成音效已预渲染成小 mp3）；淡出完的曲目立即释放，同时存在的音频实例 ≤ 10 |
| 存档 | `tt.getStorageSync / setStorageSync` | 只存在本机：关卡进度、星级、音量、侧边栏礼包领取日期 |
| 分包 | `tt.loadSubpackage({ name: 'audio' })` | 加载页进度条包含分包下载 |
| 激励视频 | `tt.createRewardedVideoAd` | 首发不启用（`rewardedAdUnitId` 留空 → 免费「再试一次」）；填 ID 后自动启用，见第 2 节 |
| 分享 | `tt.shareAppMessage`、`tt.onShareAppMessage`、`tt.showShareMenu` | 右上角菜单分享 + 结算页「分享给好友」，卡片图 `assets/share.png` |
| 录屏 | `tt.getGameRecorderManager` | 每关开局自动录（最长 290 秒），左上角小红点"录屏中"；结算页「分享通关录屏」→ `shareAppMessage({ channel: 'video', extra: { videoPath, videoTopics } })`；不足 3 秒提示"录屏失败：录屏时长低于 3 秒" |
| 侧边栏复访 | `tt.onShow`、`tt.checkScene`、`tt.navigateToScene` | game.js 启动时就同步监听 onShow；`checkScene` 返回支持才显示入口；最新一次 onShow 里 `launch_from === 'homepage' && location === 'sidebar_card'` 才能领取；奖励：下一局「移出」+1，每天一次 |
| 生命周期 | `tt.onShow / onHide`、`tt.onAudioInterruptionBegin/End` | 切后台 / 来电：暂停游戏、停所有声音 |
| 屏幕 | `tt.getSystemInfoSync`、`tt.getMenuButtonBoundingClientRect` | 安全区 + 胶囊位置 |

**BGM 无缝循环**：mp3 编码器在开头 / 结尾会加几十毫秒的延迟和补零，直接用 `InnerAudioContext.loop` 会在接缝处"咯噔"一下。抖音包的 BGM 由 `tools/douyin_bgm.py` 从无缝的 ogg 母带生成：文件 = 整数采样的循环体 + 0.5 秒循环开头的延续，带 LAME gapless 信息头；运行时 `src/platform/LoopAudio.js` 用两个 InnerAudioContext 交替，当前一路播到循环点时另一路从 0 开始，两路等功率交叉淡化 0.25 秒。构建时实测（`build/douyin-assets/bgm/report.json`）：解码后首 / 尾相对母带多出的静音 **0 ms / 0 ms**（要求 < 5 ms）；即使某机型解码器不认 gapless 头（开头多 27~49 ms），模拟接缝也没有 ≥ 5 ms 的静音窗。

**可选、没做的**（需要时再加）：排行榜（`tt.setImRankData` 等）、订阅消息、桌面快捷方式（`tt.addShortcut`）、插屏广告、Banner 广告、游戏圈 / 游戏站。

## 6. 资质与合规（必须你本人办理）

### 6.1 软件著作权（软著）—— 必须

- 抖音小游戏上线需要提供**计算机软件著作权登记证书**。
- **软件名称要和小游戏名称一致**（「美少女了个美」或「美少女了个美小游戏软件」这类，提交前看平台对名称匹配的最新要求）。
- **著作权人要和开放平台的认证主体一致**；不一致需要提供著作权人出具的**授权书**。
- 办理：中国版权保护中心（<https://www.ccopyright.com.cn/>）在线申请，或委托代理。需要源代码前后各 30 页、操作说明书（可用本仓库 README 和截图整理）。
- **「狸猫」是出品 / 品牌名，不是法律主体。** 软著著作权人、开放平台认证主体、隐私协议 / 用户协议里的运营者，都必须写**同一个真实主体名称**（公司全称或个人姓名）；游戏内、商店里保留「出品：狸猫」即可。隐私协议里该处标为 `【主体名称：须与抖音开发者账号认证主体完全一致】`。

### 6.2 版号 / 免版号

- 本游戏**没有内购**（不卖道具、不卖关卡），收入只来自激励视频广告。
- 按抖音平台目前的规则：**有付费（内购 / 虚拟支付）的小游戏需要版号**；**无内购的小游戏可以不办版号**，但要按平台要求完成**小游戏备案**（以及平台要求的 **ICP 备案 / 小程序备案**）。
- 以后如果加内购，必须先拿到版号（国家新闻出版署审批）。

### 6.3 隐私协议（必须）

- 草稿：`docs/douyin/隐私协议.md`。把 `【主体名称…】` 换成**开发者账号认证主体的完整名称**（与软著著作权人一致），再补全 `【待填写】`（联系邮箱、地址、生效日期等）后，在开放平台 **设置 → 隐私协议 / 用户隐私保护指引** 里填写或上传。
- 游戏本身**不收集**姓名、手机号、位置、通讯录；**不请求**任何系统权限（相册 / 麦克风 / 定位）。录屏文件保存在抖音临时目录，只有玩家主动点"分享"才会发布。
- 第三方：分享、录屏（以及以后开通的激励视频广告）由抖音提供，按抖音隐私政策处理。首发版不含广告。

### 6.4 适龄提示

- 加载页已显示「适龄提示 8+」（建议值：卡通画风、无暴力血腥、无付费）。最终以你在平台上按《网络游戏适龄提示》团体标准填写的结果为准；如果平台给出的年龄不同，改 `src/scenes/BootScene.js` 里的文字后重新构建。
- 加载页已显示**健康游戏忠告**全文。

### 6.5 防沉迷

- 本游戏不要求实名、没有账号体系，**防沉迷由抖音平台统一处理**（抖音账号实名 + 未成年人模式）。如果平台审核要求游戏内接入防沉迷提示，按平台给的组件接入即可。

### 6.6 美术内容规范（二次元女角色）

- 现有角色均为 Q 版校园 / 奇幻风格，**无暴露、无性暗示**。上架前请再过一遍：

  - 不能使用他人的 IP 角色、明星肖像；
  - 不能出现"最强""第一"等绝对化用语、二维码、外链。
- 本游戏角色语音由 AivisSpeech 合成，**与声优本人及任何原作无关**；语音模型许可见 `licenses/`（リダ：作者自定条款，须署名，作者注明条款可能随时变更；黄金笑：Tαkoeプロジェクト利用規約，须著作权表示「Tαkoe:AivisSpeech:黄金笑」；两者都允许法人直接商用）。上架前请再看一次各模型页面的最新条款。

### 6.7 AI 生成内容标识

- 依据《人工智能生成合成内容标识办法》（2025-09-01 起施行），**部分美术与角色语音由 AI 生成**，需要显式标识：
  - 游戏加载页已显示「部分美术与语音由 AI 生成」；

## 9. 改代码后怎么重新构建

```bash
npm install                 # 第一次
npm run build:douyin        # → build-douyin/ (= 抖音小游戏 文件夹)，并检查包体大小
npm run test:douyin         # 无真机自动化测试 (Node 无 DOM 运行 + Chromium 模拟 tt)
node tools/test-douyin.mjs --store && python3 tools/make_douyin_store.py   # 重新生成截图 / 宣传图
```
