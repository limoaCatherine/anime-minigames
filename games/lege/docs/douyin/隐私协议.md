《美少女了个美》（以下简称"本游戏"）是由 **狸猫** 出品、运营者为 **【主体名称：须与抖音开发者账号认证主体完全一致（= 软著著作权人），填公司全称或个人姓名】**（以下简称"我们"）在抖音平台提供的小游戏。我们非常重视你的个人信息与隐私保护。请你在使用本游戏前仔细阅读本协议。

## 一、我们收集哪些信息

**本游戏不收集、不上传你的任何个人信息。** 具体来说：

1. **不需要注册或登录**，不读取你的抖音昵称、头像、手机号。
2. **不申请系统权限**：不访问相册、麦克风、摄像头、定位、通讯录。
3. **游戏存档只保存在你的手机本地**（通过抖音提供的本地存储能力），内容包括：关卡进度、星级、音量设置、每日挑战与侧边栏礼包的领取日期。我们没有服务器，无法看到这些数据。卸载抖音或清除小游戏缓存后存档会被删除。

## 二、由抖音平台提供的功能

以下功能由抖音平台提供，相关信息由抖音按其《隐私政策》处理，我们无法获取：

| 功能 | 说明 |
|---|---|
| 激励视频广告（如开通） | 当前版本不含广告。今后如开通，仅在你主动点击"看广告复活"时播放，广告的展示、统计与个性化推荐由抖音广告服务处理。 |
| 游戏录屏 | 每关开局时，抖音的录屏功能会自动录制本局游戏画面（画面左上角有"录屏中"提示），视频保存在抖音的临时目录。**只有你在结算页主动点击"分享录屏"并在抖音发布页确认后才会发布**；不分享则不会上传。 |
| 分享 | 你主动点击分享时，由抖音完成分享。 |
| 侧边栏复访 | 我们只读取"本次是否从抖音首页侧边栏进入"这一启动信息，用于发放每日礼包，不读取其他信息。 |

## 三、未成年人保护

1. 本游戏适龄提示为 **8 岁以上**，内容为卡通画风的休闲消除游戏，不含付费内容。
2. 未成年人请在监护人指导下使用；防沉迷与实名认证由抖音平台统一执行。
3. 由于我们不收集任何个人信息，我们不会知道也不会处理未成年人的个人信息。

## 四、AI 生成内容说明

本游戏部分美术素材与角色语音由人工智能生成（语音使用 AivisSpeech 合成，与任何声优本人及原作无关），游戏加载页已作标识。

## 五、你的权利

由于我们不在服务器保存你的数据，你可以随时通过以下方式管理本地数据：抖音 → 我 → 设置 → 清理缓存（或删除本小游戏），即可删除全部存档。

本协议可能会随功能变化而更新，更新后会在游戏 / 小游戏资料页公布。重大变更会以合理方式提示你。
