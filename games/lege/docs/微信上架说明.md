# 《美少女了个美》微信小游戏上架说明

出品：狸猫　·　工程文件夹：`微信小游戏/`（源码构建：`npm run build:wechat` → `build-wechat/`）

> 本文依据微信开放文档整理（2026-10-11 核对）。平台规则随时可能调整，**以 mp.weixin.qq.com 后台页面和下方官方链接的最新内容为准**。

## 0. 这个工程里已经做好的

| 项目 | 说明 |
| --- | --- |
| 平台适配 | `src/platform/WechatPlatform.js`，只用 `wx.*`：`createCanvas` / `createImage` / `createInnerAudioContext` / `getStorageSync` / `onTouch*` / `onShow` / `onHide` / `loadSubpackage` / `getWindowInfo`（安全区 + 右上角胶囊避让） |
| 唯一配置文件 | `wechat.config.js`：`appid`（必填）、`rewardedAdUnitId`（首发留空） |
| 复活 / 广告开关 | `rewardedAdUnitId` 留空 → 没有任何广告，卡槽塞满时每关免费「再试一次」一次；填入广告位 ID → 自动变成「看激励视频复活」（`wx.createRewardedVideoAd`，看完才发奖励） |
| 转发 | 右上角菜单「转发」(`wx.onShareAppMessage`) + 结算页「分享给好友」(`wx.shareAppMessage`)，卡片图 `assets/share.png`（5:4，500×400） |
| 分享到朋友圈 | `wx.showShareMenu({ menus: ['shareAppMessage', 'shareTimeline'] })` + `wx.onShareTimeline`，卡片图 `assets/share_timeline.png`（1:1，500×500）。**微信目前仅 Android 支持朋友圈分享（beta）** |
| 不做的 | 抖音专属的「录屏分享」「侧边栏复访」在微信版里关闭（微信没有对应能力） |
| 分包 | 主包：代码 + 图片 + 音效；分包 `audio`：语音 + BGM（启动时 `wx.loadSubpackage` 加载） |
| 音频 | 全部 mp3（iOS 不能播 ogg），BGM 为无缝循环版 |
| 包体 | 主包约 1.15 MB / 上限 4 MB；整包约 4.05 MB / 上限 30 MB（构建时自动检查，结果写入 `build/wechat-size.json`） |
| 加载页 | 健康游戏忠告 + 「出品：狸猫 · 适龄提示 8+ · 部分美术与语音由 AI 生成」 |
| 个人信息 | 游戏不联网、不获取昵称头像 / 位置 / 好友关系等，存档只存在本机（`wx.setStorageSync`） |

包体上限出处：[分包加载](https://developers.weixin.qq.com/minigame/dev/guide/base-ability/subPackage/useSubPackage.html)、[代码包](https://developers.weixin.qq.com/minigame/dev/guide/base-ability/code-package.html)：「整个小游戏所有主包+分包大小不超过 30M；主包不超过 4M；单个普通分包不限制大小」。

## 1. 注册账号与主体认证

1. 打开 <https://mp.weixin.qq.com> → 立即注册 → 选择「小程序」，用一个**未注册过公众平台的邮箱**注册并激活。
2. 主体类型：
   - **企业**（推荐，例如「上海盖姆艾尔网络科技有限公司」）：按页面填写营业执照、管理员信息；**企业主体必须完成微信认证才能提交小程序备案**（[小游戏接入指南](https://developers.weixin.qq.com/minigame/introduction/guide)）。认证在后台「设置 → 微信认证」办理，按页面提示付费审核。
   - 个人：也能发布不开通支付的小游戏，但能力受限。
3. 完善小程序信息：名称、简称、头像、简介；**服务类目选「游戏」→ 具体三级类目**（本作建议「休闲游戏」下的消除 / 益智类，按后台可选项选择与玩法一致的一项）。
   - 头像：可用 `docs/douyin/store/icon_1024.png`（正方形，后台会自动裁成圆形）。
   - 名称注意：名称、账号主体在小游戏备案提交后**不能再改**（见第 6 节），请先定好。名称与已获批游戏重名会被驳回；仿冒知名游戏的名称也可能被拒（[小游戏备案 Q4](https://developers.weixin.qq.com/minigame/introduction/guide/nrjs.html)）。
4. 拿到 AppID：后台「开发 → 开发管理 → 开发设置 → AppID(小程序ID)」，以 `wx` 开头。

## 2. 填 AppID、安装开发者工具、导入

1. 打开 `微信小游戏/wechat.config.js`，把 `appid: 'TODO_填写你的AppID'` 改成你的 AppID；同时把 `project.config.json` 里的 `"appid"` 改成同一个（用源码构建时 `npm run build:wechat` 会自动写入）。
2. 下载安装「微信开发者工具」（稳定版）：<https://developers.weixin.qq.com/minigame/dev/devtools/download.html>，用管理员 / 开发者的微信扫码登录。
   - 其他人要预览，需在后台「管理 → 成员管理」把他们加为开发者 / 体验成员。
3. 开发者工具 → 左侧「小游戏」→「导入项目」→ 目录选 `微信小游戏` 文件夹 → AppID 选你的小游戏 → 导入。
4. 模拟器里应能看到：加载页 → 菜单 → 开始游戏。右上角「···」菜单里有「转发」「分享到朋友圈」。

## 3. 真机预览

1. 工具栏「预览」→ 用手机微信扫码，在真机上把以下内容都过一遍：
   - 刘海屏 / 底部手势条不遮挡界面；触摸点牌、道具、暂停
   - 声音：BGM 循环无断点、音效、角色语音；切到后台再回来声音正常、游戏暂停
   - 卡槽塞满 → 「再试一次」（未填广告位时）
   - 结算页「分享给好友」、右上角「转发」；Android 上「分享到朋友圈」
2. 也可以用「真机调试」查看真机日志。

## 4. 上传代码

### 方式 A：开发者工具（最简单）

工具栏「上传」→ 填版本号（例如 `3.3.0`）和备注 → 上传成功后，到 mp 后台「管理 → 版本管理 → 开发版本」能看到。

### 方式 B：命令行 miniprogram-ci（可选，适合自动化）

官方文档：[miniprogram-ci 概述](https://developers.weixin.qq.com/miniprogram/dev/devtools/ci.html)

1. mp 后台「管理 → 开发管理 → 开发设置 → 小程序代码上传」→ 生成**代码上传密钥**（下载 `private.<appid>.key`）。
2. 同一处**开启 IP 白名单**并填入运行上传命令那台机器的公网 IP（官方建议默认开启）。
3. 密钥只在本机保存，**不要提交到 Git 仓库**（本仓库 `.gitignore` 已忽略 `*.key`）。密钥一旦泄露需在后台重置。
4. 上传：

```bash
npm install -g miniprogram-ci
miniprogram-ci upload \
  --pp ./微信小游戏 \
  --pkp ./private.你的AppID.key \
  --appid 你的AppID \
  --type miniGame \
  --uv 3.3.0 \
  --ud "首发版本" \
  -r 1
```

（预览：把 `upload` 换成 `preview`，加 `--qrcode-format image --qrcode-output-dest ./preview.jpg`。）

## 5. 资质与材料

本作是 **IAA 游戏**（只靠广告变现、不开通虚拟支付；首发连广告也没有）。官方流程：[IAA 游戏发布指引](https://developers.weixin.qq.com/minigame/introduction/guide/iaa.html)
注册账号 → 名称/简称/头像、类目 → 微信认证 → **适龄提示** → **资质审核** → **版本审核** → **小游戏备案** → **小程序备案** → 发布。官方预计 IAA 游戏全程约 13–37 个工作日；开发可以同时进行。

| 材料 | 是否需要（本作） | 依据 / 说明 |
| --- | --- | --- |
| **版号**（《网络游戏出版物号核发单》） | **不需要**。只有开通虚拟支付（IAP）或棋牌-牌类等特殊类目才需要 | 资质审核时选择「**情况二：小游戏当前及未来均不需要开通虚拟支付**」、「不申请支付资质」（[资质审核(IAA)](https://developers.weixin.qq.com/minigame/introduction/guide/zzsh-iaa.html)）。若将来要做内购，需先取得版号 |
| **软著**（《计算机软件著作权登记证书》） | **一般不需要**；以下情形才需要：①游戏名称含英文或「软件」字样；②涉及品牌、公众人物合作等。《美少女了个美》不含英文，按现行规则可不交 | [资质审核(IAA)](https://developers.weixin.qq.com/minigame/introduction/guide/zzsh-iaa.html)「IAA 游戏进行备案时，遇以下情形需要提交《计算机软件著作权登记证书》」。软著登记名称需与游戏名称一致；**如果后台提示需要，以后台为准**。已有抖音版的软著可复用（著作权人须与提审主体一致） |
| **《游戏自审自查报告》** | **必填**（每次提交版本审核） | [发布流程](https://developers.weixin.qq.com/minigame/introduction/gamemaker/minigame/release.html)「[游戏自审自查报告]和[版本更新说明]是必填的」。按后台给出的示例格式写：游戏名称、主体、玩法与内容自查（无色情暴力赌博、无违法内容、AI 生成内容已标识、防沉迷 / 适龄提示）、隐私保护等，企业主体**加盖公章**（个人主体手写签名），写清日期，上传图片 |
| **适龄提示** | **必填**；建议 **8+**（卡通画面、无对抗、无陌生人社交） | [适龄提示设置指引](https://developers.weixin.qq.com/minigame/introduction/guide/slts.html)：后台「设置 → 基础设置 → 基本信息 → 适龄提示」，设置后需审核；平台会在启动页「健康游戏忠告」右侧显示。游戏加载页里写的也是 8+，保持一致 |
| **用户隐私保护指引** | **必填** | [小游戏隐私合规开发指南](https://developers.weixin.qq.com/minigame/dev/guide/open-ability/privacy.html)：后台「设置 → 服务内容声明 → 用户隐私保护指引」。本作不调用任何涉及个人信息的接口（昵称头像、位置、好友关系、相册、麦克风、剪切板等都没有），可选「**确认承诺未处理用户任何信息**」。**开通激励视频广告后**，请按后台当时的提示复核是否需要更新声明。我们自己的隐私政策文本可参考 `docs/douyin/隐私协议.md`（把其中的【主体名称】替换为你的公司全称） |
| 版本更新说明 | 必填 | 首发写「首个版本：叠三张就消的二次元消除小游戏，共 N 关 + 每日挑战」 |
| 小游戏备案材料 | 必填 | [小游戏备案](https://developers.weixin.qq.com/minigame/introduction/guide/nrjs.html)：如实介绍场景、玩法、功能并上传截图（截图尺寸、版本保持一致）。可用 `docs/douyin/screenshot_1..5`（1080×1920） |
| 小程序备案（工信部 ICP） | 必填 | 小游戏备案通过后进行：信息填写 → 平台初审 → 工信部短信核验 → 通管局审核。企业主体须先完成微信认证 |
| 著作权 / 授权材料 | 视情况 | 本作美术为原创（AI 辅助生成），语音为可商用的 AivisSpeech 模型（见 `licenses/`），无第三方 IP。若审核要求，提供 licenses 里的条款截图 |

## 6. 提交审核与发布

1. **版本审核**（[版本审核](https://developers.weixin.qq.com/minigame/introduction/guide/bbsh)，通常 1 个自然日）：后台「管理 → 版本管理 → 开发版本 → 提交审核」：
   - 选择游戏引擎（本作：不使用引擎 / 原生 Canvas）
   - 完善用户隐私保护指引、完成适龄提示
   - 填写版本更新说明，上传《游戏自审自查报告》
   - 宣传图非必填，可用 `docs/douyin/store/` 里的图或截图
   - 开发者信息里的「苹果开发者账号」为必填项（可填邮箱）
2. **小游戏备案**：「账号设置 → 小程序备案 → 去完善 → 小游戏备案 → 前往提交」。平台初审 1–2 个工作日，主管部门 10–20 个工作日。**备案提交后不能改名、不能迁移主体。**
3. **小程序备案**：小游戏备案通过后，按页面完成工信部备案（短信核验）。
4. **发布**：版本审核通过 + 小程序备案完成后，「版本管理 → 审核版本 → 提交发布」→ 全量发布。

## 7. 流量主与激励视频（上线后）

1. 开通条件（满足任一，[广告](https://developers.weixin.qq.com/minigame/dev/guide/open-ability/ad/ad.html)）：
   - 小程序累计独立访客 (UV) **> 500**，无刷粉行为且无严重违规记录；或
   - 开通游戏圈并产生有效活跃 + 发布官方帖 5 篇；或
   - 同公司主体名下已有小程序开通流量主，且连续 1 个季度有变现、无违规。
   - 资格次日刷新：满足条件后第二天再试。
2. 开通：mp 后台「功能 → 流量主」→ 开通，补充结算（财务）资料。
3. 新建广告位：流量主 → 广告管理 → 新建「激励广告」广告位 → 复制广告位 ID（形如 `adunit-xxxxxxxxxxxx`）。
4. 打开 `wechat.config.js`，填进 `rewardedAdUnitId: 'adunit-…'` → 重新上传、提审、发布。填好后游戏自动从「再试一次」切换为「看广告复活」：看完广告才复活，中途关闭不复活，拉取失败时提示稍后再试（`rewardOnAdError: false`）。不需要改任何代码。
5. 运营注意：朋友圈 / 转发分享**不能强制、不能「分享即得奖励」诱导**（[分享到朋友圈 · 运营须知](https://developers.weixin.qq.com/minigame/dev/guide/open-ability/share-timeline_game.html)）。本作分享没有任何奖励，符合要求。

## 9. 常见问题

- **导入后提示 AppID 不合法**：`project.config.json` 里还是 `TODO_…`，改成你的 AppID，或在开发者工具「详情 → 基本信息」修改；没有 AppID 时可以先选「测试号」体验。
- **真机没有声音**：检查手机媒体音量；本作已设置 `obeyMuteSwitch: false`，iOS 静音键不影响游戏声音。
- **看不到「分享到朋友圈」**：微信目前仅 Android 支持；iOS 只有「转发」。
- **想关掉朋友圈分享**：`wechat.config.js` 里 `shareTimeline: false`。
- **改了配置要不要重新构建**：直接改 `微信小游戏/wechat.config.js` 即可（再上传）；用源码的话改 `wechat/wechat.config.js` 后运行 `npm run build:wechat`。
