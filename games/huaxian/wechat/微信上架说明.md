# 《画线守护美少女》微信小游戏 上架说明

> 出品：狸猫 · v1.5.0 · 本文所有规则均摘自微信官方文档（2026-10-11 查阅，链接见各节与文末），平台规则会调整，**以提交时后台页面与官方文档为准**。
> 适用情形：**企业主体**、**只靠激励视频广告变现（IAA，不开通虚拟支付）** 的休闲小游戏。

## 0. 目录与配置

```
wechat/
├─ game.js               游戏代码 (esbuild 单文件，含 Matter.js，0.26 MB)
├─ game.json             竖屏 + 分包声明 ("subpackages": images / audio)
├─ project.config.json   微信开发者工具工程配置 (appid 默认 'YOUR_APPID'；store/ 与 .md 不上传)
├─ config.js             ★ 只需改这里：APPID / AD_UNIT_ID
├─ assets/               主包：背景图、预渲染音效、转发图 share.jpg (5:4)、朋友圈图 share_timeline.jpg
├─ subpackages/images/   分包 images：角色 / 敌人立绘
├─ subpackages/audio/    分包 audio：角色语音 + 背景音乐 (mp3)
├─ licenses/             第三方许可全文 (リダ 语音模型作者许可、AivisSpeech Engine、Matter.js)
├─ store/                提审 / 备案用素材 (不上传)
├─ 微信上架说明.md        本文 (不上传)
├─ 隐私保护指引草稿.md     (不上传)
└─ 商店文案.md            (不上传)
```

**包体（本次构建）**：主包 **0.75 MB**、images 分包 0.30 MB、audio 分包 1.40 MB，合计 **2.45 MB**。
官方限制：**主包 ≤ 4M，主包 + 全部分包 ≤ 30M，单个普通分包不限制大小，单个独立分包 ≤ 4M**（[分包加载](https://developers.weixin.qq.com/minigame/dev/guide/base-ability/subPackage/useSubPackage.html)、[代码包](https://developers.weixin.qq.com/minigame/dev/guide/base-ability/code-package.html)）。
代码包只上传白名单后缀的文件（png / jpg / js / json / mp3 / wav / txt 等，见「代码包 → 文件类型」）；`tools/test-wechat.mjs` 会检查本包所有文件都在白名单内。

`config.js`：
```js
module.exports = {
  APPID: '',        // 微信公众平台 → 开发 → 开发管理 → 开发设置 → 开发者 ID → AppID (wx 开头)
  AD_UNIT_ID: '',   // 流量主 → 广告管理 → 激励视频广告位 ID (adunit- 开头)
};
```
- 改 `APPID` 后运行 `node tools/build-wechat.mjs`，会同步到 `project.config.json` 的 `appid`（也可直接在开发者工具「详情」里改）。
- `AD_UNIT_ID` **留空 = 游戏里不出现任何「看广告」界面**：提示按钮没有「广告」角标、没有占位弹窗，提示直接免费，但看过提示的那次挑战最高 2 星。拿到广告位 ID 后填上，开发者工具里重新编译即可（运行时读取，不用重新构建）。
- 首次上线时流量主多半还没开通（见第 9 节），**保持留空提审即可**，开通后再发一个填了广告位的版本。

重新构建 / 测试（在项目根目录）：
```bash
node tools/build-wechat.mjs                 # src/ -> wechat/ (保留 config.js / 文档 / store)
node tools/test-wechat.mjs                  # 模拟 wx 的冒烟测试 (Node，无需微信)
node tools/test-wechat.mjs --store && python3 tools/make_wechat_store.py   # 重新生成提审截图 / 素材
```

## 1. 总流程（IAA 游戏）

官方 [IAA 游戏发布指引](https://developers.weixin.qq.com/minigame/introduction/guide/iaa.html)：
**注册账号 → 名称/简称/头像、类目设置 → 微信认证 → 适龄提示设置 → 资质审核 → 版本审核 → 小游戏备案 → 小程序备案 → 小游戏发布**。

- 官方给出的审核时效：不开通虚拟支付的游戏「预计需 13 - 37 个工作日」（[小游戏接入指南](https://developers.weixin.qq.com/minigame/introduction/guide/)）。
- 可并行：名称 / 头像 / 类目 与 微信认证 并行；版本审核与资质审核并行（棋牌、文化互动除外）；版本审核与小程序备案可并行提交；开发不受流程影响。
- 「企业主体必须进行微信认证才能提交小程序备案」「小游戏发布前，必须先完成版本审核和备案流程」（同上）。
- **游戏名称、账号主体一旦提交小游戏备案就不能再改**（[小游戏备案](https://developers.weixin.qq.com/minigame/introduction/guide/nrjs.html)），名称请在第 2 步就定好：建议「画线守护美少女」。

## 2. 注册小游戏账号（企业主体）

1. 打开 [微信公众平台 mp.weixin.qq.com](https://mp.weixin.qq.com/) → 右上角「立即注册」→ 账号类型选 **小程序**（微信小游戏是小程序的一个类目，见[接入指南](https://developers.weixin.qq.com/minigame/introduction/guide/)）。
2. 填写一个**未注册过公众号 / 小程序、未绑定个人微信**的邮箱和密码 → 到邮箱点激活链接。
3. 信息登记：主体类型选 **企业**，填写企业名称、统一社会信用代码（与营业执照一致），管理员姓名、身份证号、手机号；**管理员用本人微信扫码**完成身份确认（管理员微信需已实名）。
4. 主体验证：按页面提示选「对公打款」或直接进行「微信认证」（第 4 节）。
5. 登录后台 → 完善 **名称**（例：画线守护美少女）、**头像**（`store/icon_1024.png` 或 `icon_512.png`；头像须清晰、使用透明或有色背景，白底需加有色边框，不得含腾讯 / 微信标识——[常见拒绝情形](https://developers.weixin.qq.com/minigame/product/reject.html) 1.2.2 / 3.6.5）、**简介**（见 `商店文案.md`）。
6. **服务类目选「游戏」**，并选与玩法一致的游戏三级类目（例如 休闲 下最接近「物理画线 / 益智」的一项）。注意：「一旦你选择了游戏类目，该类目将不可修改变更为其他小程序类目」（常见拒绝情形 2.1.3）。

## 3. AppID

后台 **开发 → 开发管理 → 开发设置 → 开发者 ID**：复制 **AppID(小游戏ID)**（wx 开头）填入 `config.js` 的 `APPID`，运行 `node tools/build-wechat.mjs`。
同一页面的 **AppSecret 不需要**（本游戏没有服务器）。如需用命令行上传（第 6 节），在同页「小程序代码上传」生成**代码上传密钥**并配置 IP 白名单——密钥文件**不要放进本仓库**（`.gitignore` 已忽略 `private.*.key`）。
如有其他人参与开发 / 测试：**管理 → 成员管理** 添加开发者、体验成员。

## 4. 微信认证

入口：后台 **设置 → 基本信息 → 微信认证 → 详情**（[微信小程序认证指引](https://developers.weixin.qq.com/minigame/product/renzheng)）。
流程：签署《微信公众平台认证服务协议》→ 选企业类型、上传《营业执照》→ 填发票信息 → **微信支付审核费用**（金额以页面为准）→ 第三方审核公司审核，期间可能电话联系；企业可能需要用对公账户向腾讯账户打一笔指定金额验证（10 个工作日内退回）。
企业主体**必须完成微信认证才能提交小程序备案**（接入指南）。

## 5. 安装微信开发者工具、导入项目

1. 下载安装 [微信开发者工具](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html)（稳定版，Windows 64 / macOS）。
2. 打开后用**已被添加为该小游戏开发者 / 管理员的微信扫码登录**。
3. 「小游戏」→「导入项目」→ 目录选本仓库的 `wechat/` 文件夹，AppID 选 / 填你的 AppID（未注册时可先用「测试号」体验，但测试号不能提审），后端服务选「不使用云服务」。
4. 编译后模拟器里应依次看到：启动页（游戏名 +《健康游戏忠告》+ 出品：狸猫）→ 主菜单。
5. 建议在 **详情 → 本地设置** 里把「调试基础库」选为较新的版本；`game.js` 已是 ES2017 压缩代码，工程设置里「ES6 转 ES5」「上传时压缩」可保持默认。

## 6. 真机预览与上传

- **真机预览**：工具栏「预览」→ 用手机微信扫二维码。重点检查：
  - 画面：刘海屏 / 胶囊按钮不挡住画面（游戏画面放在安全区内、胶囊按钮下方），四周是粉紫渐变留边；
  - 触摸：画线流畅、只能画一笔；
  - 声音：背景音乐循环无断点、音效、角色语音；**iOS 静音键打开时 InnerAudioContext 默认不出声**（`obeyMuteSwitch` 默认值），属正常；
  - 切到后台再回来：关卡暂停、音乐暂停 / 恢复；
  - 右上角「…」→「转发」卡片（标题 + 5:4 图）；Android 上还有「分享到朋友圈」（`wx.onShareTimeline` 官方标注 Beta、暂只支持 Android）；
  - 结算面板「分享给好友」调起转发（微信不再返回转发成功回调，本游戏也**不做分享奖励**，避免「诱导分享」——常见拒绝情形 3.2.1）；
  - 填了 `AD_UNIT_ID` 时：提示按钮显示「广告」角标，看完激励视频才解锁，中途关闭不给奖励。
- **上传**：工具栏「上传」→ 填版本号（如 `1.5.0`）和项目备注 → 上传后在后台 **管理 → 版本管理 → 开发版本** 看到。可「选为体验版」给测试成员体验。
- **命令行上传（可选，适合 CI）**：官方 [miniprogram-ci](https://developers.weixin.qq.com/minigame/dev/devtools/ci.html)。需管理员在「开发管理 → 开发设置 → 小程序代码上传」下载**代码上传密钥**并配置 **IP 白名单**（未配置白名单将无法上传 / 预览）：
  ```bash
  npm i -D miniprogram-ci
  node -e "
  const ci = require('miniprogram-ci');
  const project = new ci.Project({ appid: 'wx你的AppID', type: 'miniGame', projectPath: 'wechat', privateKeyPath: '/安全位置/private.wx你的AppID.key', ignores: ['store/**/*', '*.md'] });
  ci.upload({ project, version: '1.5.0', desc: '1.5.0 首发', setting: { es6: true, minify: true } }).then(r => console.log(r));
  "
  ```

## 7. 适龄提示（必做，影响备案）

入口：**设置 → 基础设置 → 基本信息 → 适龄提示**（[适龄提示设置指引](https://developers.weixin.qq.com/minigame/introduction/guide/slts.html)）。设置后需平台审核，通过后平台会在启动页《健康游戏忠告》右侧展示 8+ / 12+ / 16+ 标记。
**建议选 8+**：指引中 8+ 的参考描述是「画面简约，以卡通和手绘风格为主」「背景、情节、角色等设计简单友好」「竞技和对抗内容以非写实的形式出现」「不存在…自由交流的陌生人社交系统」，本游戏均符合（卡通画风、无剧情、无联网社交、无内购）。
「适龄提示未设置或者未通过」是小游戏备案时效受影响的常见原因之一（小游戏备案 Q2）。

## 8. 资质审核：软著 / 自审自查报告 / 版号

**版号（网络游戏出版物号）**：**不需要**。依据官方 [资质审核(IAA)](https://developers.weixin.qq.com/minigame/introduction/guide/zzsh-iaa.html)：IAA 游戏选择「**情况二：小游戏当前及未来均不需要开通虚拟支付**」，「选择不申请支付资质」；版号批复文件对应的是「情况一」（小游戏备案 Q5 / Q8）。注意：**以后若要开通虚拟支付（内购），就需要版号**；棋牌、文化互动等特殊类目另有要求（本游戏不属于）。

**软著（《计算机软件著作权登记证书》）**：资质审核(IAA) 写明「IAA 游戏进行备案时，遇以下情形需要提交《计算机软件著作权登记证书》或对应其他授权材料：1）游戏名称含有英文、或“软件”字样；2）涉及相关品牌、公众人物合作等」。
- 本游戏中文名「画线守护美少女」不含英文和「软件」字样、无品牌 / 公众人物合作，**按该规则不是必需**；
- 但仍**建议办理**（名称写「画线守护美少女」，著作权人 = 账号主体公司）：抖音版上架要用、遇到驳回可作权属证明，拿到后把登记号填进 `src/config/GameConfig.js` 的 `copyrightRegNo`，会显示在启动页《健康游戏忠告》下方（常见拒绝情形 3.6.6 要求游戏开始画面标明著作权登记号等）；
- 名称 / 主体必须与软著一致，「软著涉嫌造假」「资质信息不匹配」都会被驳回。

**《游戏自审自查报告》**：提交审核时必填（官方 [发布流程](https://developers.weixin.qq.com/minigame/introduction/gamemaker/minigame/release) 「其中：[游戏自审自查报告]和[版本更新说明]是必填的」）。用后台提供的模板填写：游戏名称、主体、类型（休闲 / 物理画线）、内容概述（40 关，画线保护少女抵挡蜜蜂 / 文件 / 照片 / 落石，无暴力血腥、无赌博抽奖、无社交、无内购、仅激励视频广告）、防沉迷与适龄（8+）、自查结论，**加盖公章、法定代表人签字、写全年月日**（资质审核常见拒绝情形：主体表述矛盾、盖错章、签名不规范、日期不全）。

**提交入口**：**MP 首页 → 小程序备案 → 小游戏备案&发布流程指引 → 资质提交**，或 **设置 → 游戏设置 → 资质管理**；办结时限「正常情况：1-3 个自然日」。

## 9. 流量主与激励视频广告位

开通条件（[广告 · 开通条件](https://developers.weixin.qq.com/minigame/introduction/commercialization/ad/)，满足任一）：
1. **小程序累计独立访客（UV）> 500**，且无刷粉行为、未曾有严重违规记录；
2. 开通内置游戏圈并产生有效活跃，且发布官方帖 5 篇；
3. 同公司主体名下已有小程序：已开通流量主、从昨日开始持续 1 个季度有变现、无流量主违规记录 → 可直接开通。

「流量主资格需要次日刷新，请于满足条件后次日再试」。开通入口：后台 **功能（变现）→ 流量主** → 同意协议 → 补充财务资料 → **广告管理 → 新建广告位 → 激励视频广告**，复制广告位 ID（`adunit-…`）填入 `config.js` 的 `AD_UNIT_ID`，发新版本。
**不要刷量**（会封禁流量主）。上线初期 `AD_UNIT_ID` 留空，游戏完全没有广告界面，提示免费（封顶 2 星），不影响审核。
实现细节：`wx.createRewardedVideoAd({ adUnitId })` 全局单例；只有 `onClose` 回调 `res.isEnded === true` 才发奖励；拉取失败时提示「广告暂时无法播放，请稍后再试」（[激励视频广告](https://developers.weixin.qq.com/minigame/dev/guide/open-ability/ad/rewarded-video-ad.html)）。

## 10. 用户隐私保护指引 / 隐私政策

- 版本审核 step2 要求「**完善用户隐私保护指引**」（[版本审核](https://developers.weixin.qq.com/minigame/introduction/guide/bbsh.html)）。入口：后台 **设置 → 基本设置 / 服务内容声明 → 用户隐私保护指引**（以页面为准）。
- 本游戏**不调用**任何需要声明的用户信息接口（不获取头像昵称、手机号、位置、相册、麦克风、摄像头、剪贴板、微信运动等），只用本地存储保存进度。按后台表单如实勾选「未收集」/ 只填写本地存储用途即可；广告由微信广告平台处理。
- 完整的隐私政策文本见 **`隐私保护指引草稿.md`**（【】处需填写运营主体全称与联系方式）。

## 11. 版本审核（提审）

入口：**管理 → 版本管理 → 开发版本 → 提交审核**（版本审核办结时限「正常情况：1 个自然日」）：
1. 选择游戏开发对应的引擎：选「其他 / 自研（Canvas 2D）」类选项；
2. 完善用户隐私保护指引（第 10 节）、完成适龄提示设置（第 7 节）；
3. 填写**游戏内容介绍**：截图按顺序上传 `store/screenshot_0.jpg`（启动页：游戏名 +《健康游戏忠告》）→ `screenshot_1`（主界面）→ `screenshot_2`（选关）→ `screenshot_3`/`4`（玩法过程）→ `screenshot_5`（胜利结算）；全部 1080×1920 同一尺寸，不重复；
4. 上传 **《游戏自审自查报告》**（第 8 节）和**版本更新说明**（见 `商店文案.md`）；
5. 宣传图为非必填，可用 `store/promo_1920x1080.jpg`（尺寸以页面提示为准）；
6. 开发者信息里「苹果开发者账号」为必填项，可填写邮箱地址（版本审核 step4）；
7. 提交。审核结果通过「微信 → 服务通知」和站内信通知。

常见拒绝点自查（[常见拒绝情形](https://developers.weixin.qq.com/minigame/product/reject.html)）：名称 / 简介 / 功能一致；不能有诱导分享（本游戏分享无奖励）；广告不得遮挡功能（激励视频仅在玩家主动点「提示」时播放）；完成品、无崩溃；游戏开始画面全文登载《健康游戏忠告》（已在启动页）。

## 12. 备案（小游戏备案 + 小程序备案）

**12.1 小游戏备案**（IAA 的前置审批，[小游戏备案](https://developers.weixin.qq.com/minigame/introduction/guide/nrjs.html)）：
- 入口：**账号设置 → 小程序备案 → 去完善 → 小游戏备案「前往提交」**；
- 前置：资质审核通过（第 8 节）、适龄提示通过（第 7 节）；
- 要求：清晰、完整、真实介绍游戏内容（场景、玩法、功能）并上传截图（尺寸、版本一致，可用 `store/screenshot_*.jpg`）；
- 时效：平台初审 1-2 个工作日，主管部门 10-20 个工作日；**提交后不能改游戏名称和账号主体**；同名游戏已获批会被驳回（需改名）。

**12.2 小程序备案（工信部 ICP 备案）**（[小程序备案操作指引](https://developers.weixin.qq.com/minigame/product/record_guidelines.html)、[备案材料示例](https://developers.weixin.qq.com/minigame/product/record_material.html)）：
- 小游戏备案「主管部门已通过」后，按页面进入小程序备案：备案信息填写 → 平台初审 → **工信部短信核验**（收到短信后 24 小时内到 https://beian.miit.gov.cn/ 完成核验）→ 通管局审核 → 备案成功（下发备案号）；
- 材料：营业执照（原件彩色照片 / 扫描件）、法定代表人 / 小程序负责人身份证、负责人授权书（盖公章、法人手写正楷签名、日期在 3 个月内）、部分省份的承诺书等；图片 **JPG、≤200K、分辨率不低于 1500×1100**；证件有效期距提交日需大于 3 个月；
- 企业主体须先完成微信认证（第 4 节）。

## 13. 发布

版本审核通过 **且** 小程序备案完成（拿到备案号）后：**版本管理 → 审核版本 → 提交发布 → 全量发布**（[版本审核](https://developers.weixin.qq.com/minigame/introduction/guide/bbsh.html)：「版本审核通过后，需在“小程序备案”也完成后，方可发布」）。
后续更新：改代码 → `node tools/build-wechat.mjs` → 开发者工具上传 → 提审 → 发布（更新版本可申请加急：每季度 2 次，需累计注册用户 > 5000）。
