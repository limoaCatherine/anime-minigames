# 《画线守护美少女》抖音小游戏 上架说明

出品：狸猫 · 版本 1.4.0 · 本目录 `douyin/` 就是可以直接用「抖音开发者工具」打开的小游戏工程。

> 平台规则以抖音开放平台最新文档为准（本文整理于 2026-10-11，每条后面附了出处）。

---

## 0. 工程里都有什么

```
douyin/
├─ game.js              游戏代码 (由 tools/build-douyin.mjs 打包，与网页版/桌面版同一份玩法代码)
├─ game.json            竖屏 (deviceOrientation: portrait) + 分包声明 (subPackages)
├─ project.config.json  开发者工具工程配置 (appid 默认为 YOUR_APPID)
├─ config.js            ★ 唯一需要你填写的配置：APPID、AD_UNIT_ID
├─ assets/              主包资源：背景图、预渲染音效、分享图
├─ subpackages/images/  分包 images：角色 / 敌人立绘
├─ subpackages/audio/   分包 audio：角色语音 + 背景音乐
├─ licenses/            第三方许可全文 (リダ 语音模型作者许可、AivisSpeech Engine、Matter.js)
├─ store/               商店素材 (截图、图标、推广卡片、加载图、搜索结果图)，不会打进游戏包
├─ 上架说明.md / 隐私协议草稿.md / 商店文案.md   文档，不会打进游戏包
└─ build-info.json      构建信息 (包体大小、资源映射)
```

当前包体 (见 `build-info.json`)：主包约 0.73 MB，images 分包约 0.30 MB，audio 分包约 1.40 MB，合计约 2.44 MB。
平台限制：使用分包时整体 ≤ 20 MB、主包 ≤ 4 MB、单个分包 ≤ 20 MB（开通虚拟支付后整体/分包 ≤ 30 MB）。
出处：[代码包](https://developer.open-douyin.com/docs/resource/zh-CN/mini-game/develop/guide/basic-function/subpackages/introduction)、[分包加载](https://developer.open-douyin.com/docs/resource/zh-CN/mini-game/develop/guide/basic-function/subpackages/basic)

## 1. 注册开发者账号

1. 打开 [抖音开放平台](https://developer.open-douyin.com/)，用抖音扫码登录。
2. 选择「小游戏」开发者，完成**主体认证**（企业：营业执照 + 法人/管理员信息；个人主体能力有限，变现、备案以平台说明为准）。
3. 注意：**平台主体**必须与后面「软著」的著作权人一致（否则要提供授权书，见第 6 节）。
   「出品：狸猫」只是游戏里显示的品牌署名，不影响主体与资质。

## 2. 创建小游戏、拿到 AppID

1. 控制台 → 创建小游戏 → 名称填「画线守护美少女」（**必须与软著登记的软件名称一致**，见第 6 节）。
2. 进入该小游戏 → 「开发管理 / 开发设置」，复制 **AppID**（形如 `tt0123456789abcdef`）。
3. 按要求完善基础信息（名称、简介、类目、图标、截图等，文案见 `商店文案.md`，图片见 `store/`）。
   出处：[创建与信息完善](https://developer.open-douyin.com/docs/resource/zh-CN/mini-game/guide/minigame/improve-information)、[基础信息审核规范](https://developer.open-douyin.com/docs/resource/zh-CN/mini-game/operation1/norms/game-info-audit)

## 3. 填写 config.js

打开 `douyin/config.js`：

```js
module.exports = {
  APPID: 'tt0123456789abcdef',   // 第 2 步拿到的 AppID
  AD_UNIT_ID: '',                // 第 5 步拿到的激励视频广告位 ID，暂时没有就留空
};
```

- **APPID**：还需要写进 `project.config.json` 的 `"appid"`。在项目根目录运行 `node tools/build-douyin.mjs` 会自动同步；
  不想重新构建的话，直接把 `project.config.json` 里的 `"YOUR_APPID"` 改掉也可以（开发者工具导入时也能选择 AppID）。
- **AD_UNIT_ID**：游戏运行时读取，改完在开发者工具里重新编译即可，不需要重新构建。
  **留空时游戏里不出现任何「看广告」的界面**（没有占位弹窗、提示按钮上没有「广告」角标、也没有「侧边栏奖励」入口）：
  提示直接免费，但看过提示的这一次挑战最高 2 星。所以没开通流量主也可以先上线，开通后填上 ID 即可启用激励视频。

## 4. 抖音开发者工具 + 真机预览

1. 下载并安装 [抖音开发者工具](https://developer.open-douyin.com/docs/resource/zh-CN/mini-game/develop/dev-tools/mini-app-developer-instrument)。
2. 「导入项目」→ 选择 `douyin/` 目录 → 选择小游戏 AppID。
3. 模拟器里应能看到：加载进度条 → 主菜单（「出品：狸猫」）→ 选关 → 画线。
4. 点工具栏「预览」，用抖音 App 扫码在手机上试玩。请重点在真机确认（模拟测试无法覆盖，见文末）：
   - 触摸画线手感、刘海屏/胶囊按钮是否挡住右上角按钮；
   - 声音：音效、背景音乐、角色语音能否正常播放，切到后台再回来是否暂停/恢复；
   - 激励视频 (填了 AD_UNIT_ID 后)、录屏分享、右上角「…」分享、侧边栏入口；
   - 背景音乐循环一圈（约 71 秒）时接缝处是否连贯（见附录「背景音乐循环」）。
5. 包体：工具「详情 → 本地设置/项目信息」能看到主包和分包大小，应与 `build-info.json` 接近。
   `store/` 与 `.md` 文档已在 `project.config.json` 的 `packOptions.ignore` 里排除；即使工具没有排除，它们也只有约 1.5 MB，不会超过 4 MB 主包限制。

## 5. 开通流量主、创建激励视频广告位

1. 小游戏后台 → 「变现 / 流量主」→ 申请开通（需满足平台的开通条件，例如已上线、累计用户数等，以后台显示为准）。
2. 开通后 → 广告位管理 → 新建「**激励视频**」广告位 → 复制广告位 ID 填到 `config.js` 的 `AD_UNIT_ID`。
3. 本游戏的激励视频只有一个用途：**解锁某一关的提示**（看完后该关提示永久免费）。
   代码只在 `onClose` 返回 `isEnded: true`（完整看完）时发奖励，中途关闭不发奖励。
4. 平台广告规范要点：广告入口要有明确的广告标识（本游戏提示按钮上有「广告」角标）、不能默认/强制观看、不能误触、
   奖励必须真实兑现。出处：[审核常见问题-广告篇](https://developer.open-douyin.com/docs/resource/zh-CN/mini-game/guide/contactus/ad)、
   [广告小游戏运营规范](https://developer.open-douyin.com/docs/resource/zh-CN/mini-game/operation1/norms/norms)
5. 侧边栏复访：从抖音首页侧边栏进入游戏的当天，主菜单「侧边栏奖励」可领一次「免广告提示」（只在填了 AD_UNIT_ID 时显示）。

## 6. 资质：软著 / 版号 / 自审自查

**软著（计算机软件著作权登记证书）—— 必需。**
- 软著登记的软件名称要与小游戏名称一致（全称可忽略「游戏软件」等后缀；特殊符号可省略）。
- 著作权人要与平台主体名称完全一致，否则要上传盖鲜章的授权书。
- 一份软著只能对应一款在线运营的小游戏；软著必须能在中国版权保护中心「中国版权登记查询服务平台」查到，信息完全一致。
- 申请渠道：中国版权保护中心官方登记，或平台提到的火山引擎软著特惠服务；建议软件名称就写「画线守护美少女游戏软件」，版本 V1.4.0。
- 出处：[小游戏资质规范](https://developer.open-douyin.com/docs/resource/zh-CN/mini-game/operation1/norms/credential-norms-for-mini-game)

**版号（游戏出版物号）—— 只有开通内购 (虚拟支付) 才需要。**
- 本游戏只有激励视频广告、没有内购，可以不申请版号上线。若以后要加内购，需要版号且名称、运营单位与平台一致。
- 出处：[小游戏资质规范](https://developer.open-douyin.com/docs/resource/zh-CN/mini-game/operation1/norms/credential-norms-for-mini-game)、
  开放平台论坛 FAQ（无版号能否上线 / 能否开通 iOS）：https://developer.open-douyin.com/forum/post/647461cda2c591e9aa1ee8f4

**自审自查报告**：现在在后台「基础信息 / 基础设置 → 资质信息 → 游戏自审自查报告」勾选确认即可，无需上传文件（出处同上）。

**小游戏备案 + ICP 核准**：基础信息完善、版本审核通过后，平台会协助提交「小游戏备案」；之后在后台发起 ICP 核准，
平台初审后进入管局审核（约 20 个工作日），负责人要在 24 小时内完成工信部短信核验。
出处：[小游戏备案申报](https://developer.open-douyin.com/docs/resource/zh-CN/mini-game/guide/minigame/game-filing-application-works)、
[ICP 核准指引](https://developer.open-douyin.com/docs/resource/zh-CN/mini-game/guide/minigame/icp/icp-filings)

## 7. 隐私协议

- 用 `隐私协议草稿.md` 作为基础，确认「运营者名称 / 联系方式 / 生效日期」后发布到一个可公开访问的网页（或按平台要求在后台填写）。
- 本游戏自身**不收集个人信息、不联网**：存档只保存在本机（tt.setStorageSync）；广告、录屏、分享由抖音平台提供。
- 后台若有「用户隐私保护指引 / 隐私协议」配置项，按实际情况填写：本游戏不调用位置、通讯录、相册、麦克风、摄像头、用户信息授权等接口。

## 8. 适龄提示

- 自审自查与商店信息中按《网络游戏适龄提示》团体标准（8+ / 12+ / 16+）选择。
- 建议 **8+**：卡通画风、无暴力血腥、无内购、无社交聊天；关卡里的「老板 / 相亲阿姨 / 加班文件」都是轻喜剧元素。
  最终以你的判断和平台审核意见为准。

## 9. 上传与提审

1. 确认 `config.js` 已填 APPID 和 AD_UNIT_ID，运行 `node tools/build-douyin.mjs`（会同步 appid 并检查包体）。
2. 开发者工具 → 「上传」→ 填版本号 `1.4.0` 和版本说明。
3. 后台「版本管理」→ 选择刚上传的版本 → 提交审核。审核前确认：
   - 基础信息、类目、图标、截图（`store/screenshot_1..5.jpg`，1080×1920）已上传；
   - 软著已通过、自审自查已确认、隐私协议已填写；
   - 推广卡片 `store/promo_card_494x670.jpg`、加载图 `store/loading_640x1385.jpg`、搜索结果图 `store/search_345x150.jpg`（若后台要求）。
     规格出处：[流量推广配置规范](https://partner.open-douyin.com/docs/resource/zh-CN/mini-game/operation1/norms/promote-spec)
4. 审核通过后发布；然后按第 6 节完成备案 / ICP 核准。

- 真实广告的填充、`isEnded` 回调、广告关闭后音乐恢复；
- 录屏文件的实际生成与「发布视频」页面、分享卡片的展示；
- 侧边栏 `checkScene` / `navigateToScene` 在当前抖音版本里的可用性和启动参数格式；
- 刘海屏/胶囊按钮在不同机型上的安全区。

## 附：背景音乐循环

mp3 编码器会在文件开头补约 25 ms、结尾补约 21 ms 的静音，InnerAudioContext 的 `loop=true` 不会去掉，循环接缝会有约 46 ms 的空白。
所以抖音版的 `subpackages/audio/bgm/bgm_main_loop.mp3` 是「完整一遍 + 开头 1.5 秒」，游戏里用两个 InnerAudioContext 交替：
一路播到 71.111 秒（循环长度）时，另一路从头开始，再用 0.3 秒线性交叉淡化切过去（两路此时播放的是同一段音乐）；
万一那一刻游戏卡住，当前一路播完时也会立刻接上另一路。真机上请留意接缝处是否有轻微的「重影」（两路启动延迟不同时会有），
如有，可调整 `src/platform/TTAudio.js` 里 `TTLoopAudio` 的 `fade` / `delay` 参数。
