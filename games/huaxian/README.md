# 《画线守护美少女》

出品：狸猫

**⬇ [下载 Windows 版（huaxian-shouhu-windows.zip）](https://github.com/limoaCatherine/anime-minigames/releases/download/huaxian-v1.5.0/huaxian-shouhu-windows.zip)** —— 解压后双击 `画线守护美少女\画线守护美少女.exe`，不用安装，离线就能玩

**⬇ [下载网页版（huaxian-shouhu-web.zip）](https://github.com/limoaCatherine/anime-minigames/releases/download/huaxian-v1.5.0/huaxian-shouhu-web.zip)** —— 解压后双击 `画线守护美少女-网页版\index.html`，用浏览器离线就能玩

Windows 弹出「Windows 已保护你的电脑」时：点「更多信息」→「仍要运行」。
