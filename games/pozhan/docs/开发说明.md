# 次元破绽！ 开发说明（v1.3）

二次元梗图找茬小游戏。竖屏 540×960，HTML5 Canvas + ES Modules，用 esbuild 打包；Windows 版用 Electron 包一层。出品：狸猫。
只想玩的话看根目录 [README](../README.md)，去 Releases 下载即可，这份文档是给改代码、打包的人看的。

## 快速开始

需要 Node.js 18+（生成音频、商店图的脚本另需 Python 3）。

```
npm install
npm run build              # → dist/，双击 dist/index.html 即可离线运行（file:// 可用，不需要服务器）
npm run serve              # 或者起本地服务 http://localhost:8767/dist/index.html
npm run desktop            # 用 Electron 打开桌面版（开发调试）
npm run package:win        # Windows x64 → release/次元破绽/次元破绽.exe（含 licenses/）
python3 tools/make_release.py [输出目录]   # 生成 Release 用的 ciyuan-pozhan-windows.zip / ciyuan-pozhan-web.zip
```

`tools/start.bat` 是给「源码 + dist」一起分发时用的 Windows 启动脚本（有 Python / Node 就起本地服务，没有就直接打开 dist/index.html）。

## 测试

```
npm run verify-levels      # 关卡数据校验：热区数量 / 重叠 / 出界，解谜关 BFS 可达性与死局检查

```

## 目录结构

```
src/
  core/       引擎：游戏循环、场景管理、输入、资源加载、补间、几何
  scenes/     启动 / 菜单 / 选关 / 关卡
  systems/    音频、语音、BGM、混音、弹幕、特效、存档、广告、解谜状态机
  ui/         面板与控件（设置、制作人员、结算、弹窗、字幕）
  config/     全部关卡与数值（只在这里改难度）
  platform/   平台适配层：web.js（浏览器 / Electron）、douyin.js（tt.*）、wechat.js（wx.*），后两者共用 minigame.js
  art/        程序绘制的场景与道具（图层名对应关卡配置里的 a:）
assets/       图片、语音、BGM、音效
desktop/      Electron 主进程与图标
platforms/    抖音 / 微信小游戏的 platform-config.js 模板（AppID、广告位 id 只在这里填）
tools/        构建、打包、测试、素材生成脚本
docs/         本文档、licenses/（规约全文）、screenshots/（README 截图）、上架资料/（小游戏上架说明、隐私协议草稿、商店文案与商店图）
```

核心代码只通过 `Platform` 访问画布、图片、音频、存储、输入、广告、分享，所以同一份游戏逻辑能跑在网页、Windows、抖音、微信四个平台上。

## 关卡配置

关卡内容和难度全部在 `src/config/`，系统代码里没有按关卡写的特殊分支。

1. 在 `src/config/levels/ch1.js`～`ch3.js` 里新增一个关卡对象（照着现有关卡抄最快）：`id`、`type`（`find` / `diff` / `puzzle` / `word`）、`title`、`cast`、`sanity`、`layers`（画面图层），找茬类写 `spots`（最后一处可标 `tricky: true`，可选 `egg` 彩蛋），解谜类写 `zones` / `combines` / `rules` / `hints`。坐标都是相对场景宽高的 0～1 归一化坐标，详细约定见 `src/config/LevelConfig.js` 顶部注释。
2. 在 `src/config/LevelConfig.js` 的 `LEVELS` 数组和对应章节 `CHAPTERS[].levels` 里加上它。
3. 跑 `npm run verify-levels`：会检查热区数量、重叠、出界，解谜关会用 BFS 确认正经结局可达、不会走进死局。
4. 用 `node tools/preview.mjs L14` 生成带热区叠加的预览图对一下位置，最后 `npm test`。

星级、提示冷却、放大镜等数值在 `src/config/GameConfig.js`；道具在 `ItemConfig.js`，每日一图在 `DailyConfig.js`，音量与 BGM 在 `AudioConfig.js`，配音风格在 `VoiceConfig.js`。

## 广告配置

默认没有广告。规则在网页、Windows、抖音、微信四个平台上一样：

- **激励视频广告位 id 为空**（默认）：游戏里不出现任何「看广告」按钮。精确提示改为免费，两次之间冷却 45 秒；理智归零时每关有 1 次免费「再试一次」。用了这两样最多 2 星。
- **填了广告位 id**：自动恢复「看广告」入口，不用改代码。抖音填 `platforms/douyin/platform-config.js`，微信填 `platforms/wechat/platform-config.js`（构建后在各自工程根目录的 `platform-config.js`）。网页 / Windows 版本身没有广告 SDK，如果要接，用 `AdService.setProvider(fn)` 注入。

## 玩法细节
| 类型 | 说明 |
| --- | --- |
| 找不合理 | 点出画面里 N 处不合理，最后一处是刁钻点；点错扣理智。L13 找齐后还有一道问答 |
| 找不同 | 上下两图找不同，两张图都能点 |
| 助她脱困 / 换装 | 点击、长按、滑动、拖动场景物体，把道具拖到目标上，道具之间叠放可以组合 |
| 文字拼字 | 拖动 / 拆分汉字，凑出正确的字或咒语 |

每个解谜关都有一个正经结局（通关）和一个沙雕结局（收集成就，不算通关）。
提示：每关先送 1 次免费区域提示，用掉后 75 秒回复 1 次。精确提示：配了激励视频广告位时看广告获得；没配（网页版、桌面版、首发的小游戏）时免费，两次之间冷却 45 秒。
理智归零：配了广告位时可看广告理智回满；没配时每关有 1 次免费「再试一次」。
星级：错 ≤1 次且没用精确提示、没复活 = 3 星；错 ≤3 次、精确提示 ≤1 次、复活 ≤1 次 = 2 星；其余 1 星。

## 音频
- 语音：VOICEVOX 日语配音 + 简体中文字幕，响度 -20 LUFS；BGM 程序化作曲，-22 LUFS。
- 格式：全平台只用 mp3（iOS 不能播 ogg）。BGM 文件 = 一整轮 + 开头 0.5 秒，两个播放器在循环点做 0.15 秒等功率交叉淡化，消除 mp3 编码填充造成的接缝空隙。
- 默认音量：语音 0.3、音效 0.12、BGM 0.15；语音播放时 BGM 压低到 ×0.55；同一时间只播一句（0.6 秒冷却，高优先级打断低优先级）。
- 署名：VOICEVOX:満別花丸 / VOICEVOX:冥鳴ひまり / VOICEVOX:四国めたん / VOICEVOX:九州そら / VOICEVOX:あんこもん
