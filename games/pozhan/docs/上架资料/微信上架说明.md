# 《次元破绽！》微信小游戏上架说明

出品：狸猫 · 运营主体：上海盖姆艾尔网络科技有限公司 · 版本 v1.3.0 · 本文写于 2026-10-11

> 标注【未核实】的内容没有在微信官方文档里找到逐字原文，请以公众平台 / 开发者工具里的实际提示为准。
> 官方文档入口：小游戏接入指南 https://developers.weixin.qq.com/minigame/introduction/guide

## 快速步骤 (先看这里，详细说明在后面各节)

1. **注册**：mp.weixin.qq.com 注册「小程序」账号，主体选企业，服务类目选「游戏 → 休闲」(一级类目选错只能重注册)。→ 第二节
2. **微信认证**：企业主体必须先认证，才能做后面的备案。【未核实：认证费用以后台为准】→ 第二节
3. **拿 AppID**：「开发管理 → 开发设置」复制 wx 开头的 AppID，填进 `微信小游戏/project.config.json` 的 `"appid"`。→ 第二节
4. **导入试玩**：安装微信开发者工具 → 导入 `微信小游戏/` → 编译 →「预览」用手机扫码真机试玩。→ 第三节
5. **上传**：工具里点「上传」(版本号 1.3.0)，或双击 `微信小游戏/upload.bat` 用 CLI 上传 (先在工具「设置 → 安全设置」打开服务端口)。→ 第四节
6. **后台资料**：设置适龄提示；资质管理选「不需要开通虚拟支付」(IAA，不需要版号)；用户隐私保护指引选「确认承诺未处理用户任何信息」。→ 第五节
7. **提审**：版本管理 → 提交审核，填游戏内容介绍、上传盖章的《游戏自审自查报告》和版本更新说明。【未核实：自审报告没有官方模板，按提审页示例填】→ 第五节
8. **备案**：「账号设置 → 小程序备案」完成小游戏备案 + 小程序备案 (ICP)，期间不要改名或换主体。→ 第五节
9. **发布**：审核和备案都通过后，版本管理里「提交发布 → 全量发布」。
10. **以后再开广告**：上线后累计访客 UV > 500 可开通流量主 → 建激励视频广告位 → 把 id 填进 `微信小游戏/platform-config.js` 的 `rewardedAdUnitId` → 版本号 +1 重新上传提审。首发保持留空。→ 第六节

## 一、工程在哪里、要改什么

发布包里的 `微信小游戏/` 就是完整的小游戏工程 (由 `npm run build:wechat` 生成)：

```
微信小游戏/
├── project.config.json   ★ AppID 写在这里的 "appid" (默认 touristappid = 游客模式，只能本地跑)
├── platform-config.js    ★ 其余唯一需要填写的配置：激励视频广告位 id、分享标题 / 分享图
├── upload.bat            Windows 一键上传 (调用微信开发者工具 CLI，见第四节)
├── game.js               入口
├── game.json             竖屏、隐藏状态栏、分包声明 (subpackages: audio)
├── js/main.js            游戏代码 (与网页 / 桌面 / 抖音版共用核心，平台差异在 src/platform/wechat.js)
├── images/  sfx/         主包：图片、预渲染音效 (含 5:4 分享图 images/share_card.jpg)
└── audio/                分包「audio」：配音 + BGM (进游戏后后台下载，下载完之前只显示字幕)
```

`platform-config.js` 内容：

```js
module.exports = {
  rewardedAdUnitId: '',                       // 激励视频广告位 id (adunit-…)。首发留空！见第六节
  shareTitle: '',                             // 转发标题，留空用「次元破绽！这张图毫无破绽……吗？」
  shareImageUrl: 'images/share_card.jpg',     // 转发卡片图 (5:4)
  shareImageUrlId: '',                        // (可选) 公众平台审核通过的转发图片编号
};
```

**广告位留空时的行为 (统一广告策略，网页 / 桌面 / 抖音 / 微信一致)**：游戏里不出现任何「看广告」按钮，也没有占位广告；精确提示改为免费 + 45 秒冷却，理智归零改为每关 1 次免费「再试一次」(两者照样计入星级，最多 2 星)。流量主开通后把 id 填进来重新上传，「看广告」入口自动出现，不用改代码。

### 与抖音版的区别
- 没有抖音专属功能：**首页侧边栏复访礼包、录屏分享都去掉了**。
- 结算页改为「分享给好友」(wx.shareAppMessage)，右上角菜单开了「转发」和「分享到朋友圈」(朋友圈官方说明目前仅安卓支持)。**分享不发任何奖励**，避免诱导分享。
- 激励视频关闭了 1004 兜底分享页 (`disableFallbackSharePage: true`)：没有广告时提示「暂时没有可看的广告」，不会弹「分享得奖励」。
- 短音效用 `wx.createInnerAudioContext({ useWebAudioImplement: true })` 的 5 个播放器轮流播放；配音 / BGM 用默认实现。
- 新版本发布后，老用户下次打开会收到「发现新版本，是否重启」的提示 (wx.getUpdateManager)。

## 二、注册小游戏、拿 AppID

1. 打开 https://mp.weixin.qq.com ，「立即注册」→ 选「小程序」，用公司邮箱注册，主体选「企业」，按页面完成主体信息与管理员验证。【未核实：注册页的具体按钮文字以页面为准】
2. 注册时服务类目选「游戏」(一级类目固定为游戏，**选错只能重新注册**)，二级类目选「休闲」(本游戏是找茬 / 解谜)。
   类目规则：https://developers.weixin.qq.com/minigame/introduction/guide/type.html
   (二级类目发布前可改、发布后不能改；三级类目在「资质管理」里改，改后需资质审核并发新版本)
3. 设置名称「次元破绽」、简介、头像 (图标用 `docs/上架资料/商店截图/图标_512x512.png`)。名称要和软著 / 备案信息一致。
4. **微信认证**：企业主体必须先完成微信认证才能提交小程序备案 (接入指南原文：「企业主体必须进行微信认证才能提交小程序备案」)。【未核实：认证费用 (常见说法 300 元/年) 以后台为准】
5. 拿 AppID：公众平台 →「开发管理 → 开发设置」里的 AppID (wx 开头)。
6. 把 AppID 填进 `微信小游戏/project.config.json` 的 `"appid"`，替换 `touristappid`。
7. 在「成员管理」里把要上传代码的人加为「开发者」。

## 四、上传代码

### 方式 A：开发者工具里点「上传」
填版本号 (如 `1.3.0`) 和备注 → 上传。上传后在公众平台「管理 → 版本管理」能看到「开发版本」。

### 方式 B：命令行 (Windows)
官方 CLI 文档：https://developers.weixin.qq.com/minigame/dev/devtools/cli.html
前提：① 已安装开发者工具并登录；② 工具「设置 → 安全设置」里**打开服务端口**；③ `project.config.json` 里是正式 AppID。

命令 (官方格式 `cli upload --project <项目路径> -v <版本号> -d <备注>`，Windows 下 CLI 是安装目录里的 `cli.bat`)：

```bat
"C:\Program Files (x86)\Tencent\微信web开发者工具\cli.bat" upload --project "D:\次元破绽\微信小游戏" -v 1.3.0 -d "次元破绽 v1.3.0"
```

- 把 `D:\次元破绽\微信小游戏` 换成你解压后的实际路径 (CLI 要求**绝对路径**)。
- 开发者工具默认安装在 `C:\Program Files (x86)\Tencent\微信web开发者工具\`【未核实：以你电脑上的实际安装位置为准】。
- 也可以直接双击 `微信小游戏\upload.bat`，它就是上面这条命令 (项目路径自动取 bat 所在目录)；装在别处的话改 bat 里 `set CLI=` 那一行。
- 加 `-i D:\upload-info.json` 可以把本次上传的包大小信息输出到文件。
- 没登录时先运行 `cli.bat login` 扫码。

## 五、提审与发布 (IAA = 只靠广告变现、没有内购)

官方 IAA 流程：https://developers.weixin.qq.com/minigame/introduction/guide/iaa.html
注册账号 → 名称 / 简称 / 头像、类目设置 → 微信认证、适龄提示设置、资质审核 → 版本审核 → 小游戏备案 → 小程序备案 → 发布。
多个环节可以并行 (游戏开发、版本审核与资质审核可并行；版本审核可与备案并行)。接入指南写的审核时效：**不开通虚拟支付的游戏预计 13–37 个工作日**。

### 资质清单
- [ ] **资质审核 (IAA)**：https://developers.weixin.qq.com/minigame/introduction/guide/zzsh-iaa.html
  入口：公众平台「设置 → 游戏设置 → 资质管理」，选「情况二：小游戏当前及未来均不需要开通虚拟支付」，选与内容一致的三级类目，选「不申请支付资质」。
- [ ] **版号**：IAA 游戏不需要网络游戏出版物号 (版号是开通虚拟支付 / IAP 的必填材料：https://developers.weixin.qq.com/minigame/introduction/guide/zzsh-iap.html )。
- [ ] **软著 (计算机软件著作权登记证书)**：IAA 游戏只有在「名称含英文或『软件』字样」或「涉及品牌、公众人物合作」时才必须提交。《次元破绽》不属于这两种情况，但仍**建议办理**：以后开内购需要，也能证明作品归属；名称要与软著登记名一致。
- [ ] **适龄提示**：公众平台「设置 → 基础设置 → 基本信息 → 适龄提示」，提交后需审核，通过后启动页统一展示。https://developers.weixin.qq.com/minigame/introduction/guide/slts.html
  建议按实际内容评估 (无暴力血腥、无内购、无社交聊天)，可参考 8+ 档的标准；游戏内如自己也写适龄提示，要和后台一致。
- [ ] **游戏自审自查报告** (提审必填) 与 **版本更新说明** (提审必填)：提审时按页面提示填写「游戏内容介绍」(截图用 `docs/上架资料/商店截图/`)。自审报告企业主体需加盖公章，以图片上传。【未核实：官方未提供可下载的 Word 模板，格式要求来自开放社区回答；以提审页面示例为准】
  发布流程中「[游戏自审自查报告]和[版本更新说明]是必填的」：https://developers.weixin.qq.com/minigame/introduction/gamemaker/minigame/release
- [ ] **小游戏备案 + 小程序备案 (ICP)**：https://developers.weixin.qq.com/minigame/introduction/guide/nrjs.html
  入口「账号设置 → 小程序备案 → 去完善」。备案信息里的游戏名称、主体要和提审时完全一致；**备案提交后到小程序备案完成前不能改名 / 迁移主体**。常见卡点：资质审核没过、适龄提示没设置或没通过。
- [ ] **用户隐私保护指引**：https://developers.weixin.qq.com/minigame/dev/guide/open-ability/privacy.html
  本游戏不调用任何需要隐私授权的接口 (不取昵称头像、位置、相册、剪贴板、麦克风、摄像头)，只在本机存档，所以在「设置 → 服务内容声明 → 用户隐私保护指引」选「确认承诺未处理用户任何信息」即可。完整的隐私政策草稿见 `docs/上架资料/隐私协议草稿.md` 末尾「微信小游戏版适用说明」。
- [ ] **素材版权**：同 `docs/上架资料/抖音上架说明.md` 第 8 节 —— 立绘 / 背景需能证明原创或已获商用授权；5 位 VOICEVOX 配音角色 (満別花丸、冥鳴ひまり、四国めたん、九州そら、あんこもん) 均允许企业商用、只需署名，游戏内「设置 → 制作人员」已署名，规约全文见 `docs/licenses/`。

### 提审步骤
1. 公众平台「管理 → 版本管理」→ 开发版本 → 选为体验版，内部扫码再测一轮。
2. 「提交审核」：填写游戏内容介绍、上传自审自查报告、版本更新说明 → 提交。
3. 审核通过后会在「微信 → 服务通知」收到提醒 → 版本管理里「提交发布」→ 全量发布。

## 六、流量主 (激励视频广告) 门槛与接入

官方说明：https://developers.weixin.qq.com/minigame/dev/guide/open-ability/ad/ad
满足任一条件即可在公众平台「功能 → 流量主」开通：
1. 累计独立访客 (UV) > 500，且无刷粉行为、无严重违规记录；
2. 开通内置游戏圈并产生有效活跃，且发布官方帖 5 篇；
3. 同公司主体下已有开通流量主、连续一个季度有变现且无违规的小程序。
资格次日刷新 (满足条件后第二天再试)。

**所以首发版本 `rewardedAdUnitId` 必须留空** —— 游戏会自动隐藏所有看广告按钮，提示 / 复活走免费规则，审核时不会看到任何占位广告。上线、开通流量主后：
1. 「流量主 → 广告管理」新建「激励视频」广告位，复制 `adunit-` 开头的 id；
2. 填进 `微信小游戏/platform-config.js` 的 `rewardedAdUnitId`；
3. 版本号 +1 重新上传、提审、发布。

激励视频接入规则 (已实现)：只有 `onClose` 回调 `isEnded = true` 才发奖励；中途关闭不发；拉取失败 (如 1004 无合适广告) 提示「暂时没有可看的广告，等会儿再试」，不卡流程。广告只用于「精确提示」和「理智回满」，不用于解锁关卡，没有插屏 / 强制广告。
API：https://developers.weixin.qq.com/minigame/dev/api/ad/wx.createRewardedVideoAd.html ；指南：https://developers.weixin.qq.com/minigame/dev/guide/open-ability/ad/rewarded-video-ad.html

## 七、上线前真机自测清单
- [ ] iPhone (刘海屏) / 安卓各一台：顶部内容不被胶囊按钮挡住，底部不压 Home 条。
- [ ] 声音：iOS 上 BGM / 配音 / 音效都能播 (全部是 mp3，没有 ogg)；BGM 一首放完一轮时听不到断档；静音键打开时的表现。
- [ ] 进第 1 关前后，音频分包是否已下载 (弱网下先只有字幕，下载完自动出声)。
- [ ] 切到后台再回来：关卡自动暂停，BGM 停止 / 恢复。
- [ ] 结算页「分享给好友」、右上角「转发」「分享到朋友圈」(安卓) 的卡片标题和图片。
- [ ] 没填广告位时：全游戏找不到「广告」字样；提示按钮冷却显示正常；失败时有「再试一次」(每关 1 次)。
- [ ] (开通流量主后) 看完 / 中途关闭 / 无广告三种情况。

## 八、自动化测试 (开发用)
`npm run build:wechat && npm run test:wechat`：在 Node 里模拟 wx 对象 + 画布，无 DOM 运行 `build-wechat/` 产物，覆盖工程文件格式与包体积、安全区布局、触摸通关、音效池与分包音频、分享、激励视频三种结果、切后台、重启后存档、未配置广告位时的免费提示 / 再试一次。
**局限：** 模拟环境不能验证真机的广告 / 分享 / 音频并发上限 / 性能，请按第七节在真机上过一遍。
