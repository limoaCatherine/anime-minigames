# 《次元破绽！》抖音小游戏 上架说明

出品：狸猫 · 版本 v1.3.0 · 本文写于 2026-10-11

抖音工程在发布包的 **`次元破绽/抖音小游戏/`** 文件夹 (源码仓库里由 `npm run build:douyin` 生成到 `build-douyin/`)。
标 **【未核实】** 的条目是没能在官方文档里找到原文、或者页面没抓到正文的，提交前请在抖音开放平台再确认一次。

## 一、工程结构

```
抖音小游戏/
├── game.js               入口 (官方要求的三件套之一)
├── game.json             竖屏、隐藏状态栏、分包声明 (官方要求)
├── project.config.json   开发者工具项目配置，appid 在这里 (官方要求)
├── platform-config.js    ★ 你唯一需要填写的配置：AppID、激励视频广告位 id、分享模板 id、录屏话题
├── js/main.js            游戏代码 (与网页版 / 桌面版共用同一套核心，抖音差异都在适配层)
├── images/               图片 (PNG 已量化压缩)
├── sfx/                  预渲染音效 (84 个小 mp3)
├── audio/                分包「audio」：配音 49 句 + 背景音乐 2 首
└── README.txt            简要说明 (打包时被 packOptions.ignore 排除)
```

- 必需文件 game.js / game.json / project.config.json：
  https://developer.open-douyin.com/docs/resource/zh-CN/mini-game/develop/guide/dev-guide/bytedance-mini-game
- project.config.json 字段 (appid / setting / projectname / packOptions)：
  https://developer.open-douyin.com/docs/resource/zh-CN/mini-game/develop/dev-tools/code-edit/project-config
- game.json 配置 (deviceOrientation / showStatusBar / subPackages)：
  https://developer.open-douyin.com/docs/resource/zh-CN/mini-game/develop/framework/mini-game-configuration/

### 包体大小 (v1.3.0 实测)

| 部分 | 大小 | 官方上限 |
| --- | --- | --- |
| 主包 (代码 0.24 MB + 图片 1.33 MB + 音效 0.43 MB) | **2.00 MB** (1.91 MiB) | 4 MB |
| 分包 `audio` (配音 1.08 MB + BGM 2.00 MB) | **3.07 MB** (2.93 MiB) | 20 MB |
| 合计 | **5.07 MB** (4.84 MiB) | 20 MB (开通虚拟支付后 30 MB) |

官方限制：不分包时整包 ≤20 MB；分包后整包 ≤20 MB、主包 ≤4 MB、单个分包 ≤20 MB；计算时排除点开头文件、node_modules 和 .map。
https://developer.open-douyin.com/docs/resource/zh-CN/mini-game/develop/guide/basic-function/subpackages/introduction

分包 `audio` 用 `tt.loadSubpackage` 在进入菜单后**后台下载**，不阻塞启动；下载完成前只显示字幕 (游戏照常可玩)。基础库低于 1.88.0 的老客户端没有分包能力，会直接下载整包，代码已兼容。

**CDN 方案 (可选，目前不需要)：** 如果以后加内容超过 20 MB，可以把 `audio/` 放到自己的 HTTPS CDN，再把 `src/platform/douyin.js` 里 `assetPath()` 的 `audio/` 前缀换成 CDN 地址，并在开发者后台「开发设置 → 服务器域名」把 CDN 域名加到 download 合法域名。【未核实：小游戏远程音频的域名白名单具体菜单位置】

## 二、在抖音开发者工具里打开

1. 下载安装「抖音开发者工具」(官方 IDE)：开发工具文档入口 https://developer.open-douyin.com/docs/resource/zh-CN/mini-game/develop/dev-tools/mini-app-developer-instrument (页面里有下载链接)
2. 用抖音开放平台账号扫码登录。
3. 选「导入项目」→ 目录选 `次元破绽/抖音小游戏` → AppID 填你的小游戏 AppID (还没有的话可以先用「测试号」体验) → 确定。
4. 模拟器里能看到菜单，就说明导入成功。可以点「预览」用手机抖音扫码真机试玩。

> 开发者工具里**不能调试录屏** (官方说明录屏需真机)；侧边栏可以用 IDE 模拟 (见第五节)。

## 三、需要填写的两处 (都在一个文件里)

打开 **`抖音小游戏/platform-config.js`**：

```js
module.exports = {
  appId: '',               // ① 小游戏 AppID (tt 开头)，开发者后台 → 开发管理 → 开发设置 里复制
  rewardedAdUnitId: '',    // ② 激励视频广告位 id，流量主 → 广告管理 → 新建「激励视频」后复制
  shareTemplateId: '',     // (可选) 分享模板 id
  videoTopics: ['次元破绽', '找茬', '二次元'],   // 录屏分享带的话题
};
```

- **AppID 还要和 `project.config.json` 里的 `"appid"` 一致**。导入项目时在 IDE 里填 AppID，IDE 会自动写进 project.config.json；手动改也可以 (默认是占位 `YOUR_DOUYIN_APPID`)。两边不一致时，游戏会在 IDE 控制台打印一条提醒。
- `rewardedAdUnitId` **留空 = 游戏里不出现任何「看广告」按钮** (v1.3 统一广告策略：精确提示改为免费 + 45 秒冷却，复活改为每关 1 次免费「再试一次」，星级规则不变)。流量主要游戏上线、有一定流量后才能开通，所以**首发留空提审即可**；开通后填上 id 重新上传，「看广告」入口自动出现，不用改代码。
- 重新运行 `npm run build:douyin` 时，会保留你已经改过的 platform-config.js 和 project.config.json 里的 appid。

激励视频广告需要先开通「流量主」并在流量主里创建广告位：
- API：https://developer.open-douyin.com/docs/resource/zh-CN/mini-game/develop/api/javascript-api/ads/tt-create-rewarded-video-ad (前提：「商业化 → 流量主」开通，「流量主 → 广告管理」创建激励视频广告位)
- 接入指南：https://developer.open-douyin.com/docs/resource/zh-CN/mini-game/develop/guide/open-ability/ad/incentive-ads

广告逻辑说明：只有完整看完 (`isEnded=true`，或平台在无广告时的兜底分享返回 `count>0`) 才发奖励；中途关闭不发；拉取失败 (如错误码 1004 无合适广告) 时提示「暂时没有可看的广告，等会儿再试」，不卡流程。广告只用于「提示」和「理智回满」，**不用于解锁关卡**，也没有强制弹出的广告。

## 四、上传与提审步骤

1. IDE 里点「上传」，填版本号 (如 1.3.0) 和备注。
2. 登录抖音开放平台 → 控制台 → 你的小游戏 → 版本管理，找到刚上传的版本 → 设为测试版，在真机上把下面「自测清单」走一遍。
3. 资质、基础信息、备案/核准都通过后，点「提交审核」。
4. 审核通过后「发布」。

自测清单 (真机)：
- [ ] 刘海屏 / 带 Home 条的手机上，返回、齿轮、提示按钮都不被挡 (游戏画面自动避开状态栏、右上角胶囊和底部安全区)
- [ ] 配音和 BGM 在进菜单几秒后出现 (分包加载)；静音按钮有效
- [ ] 看激励视频 → 完整看完拿到提示；中途关闭不给；切后台再回来游戏暂停
- [ ] 通关后结算页「分享本局录屏」可点，能发布到抖音 (录屏 >3 秒)
- [ ] 菜单左上「侧边栏礼包」→ 去首页侧边栏 → 从侧边栏回来 → 立即领奖 (+2 提示券，每天一次)
- [ ] 退出再进，进度还在

## 七、测试是怎么做的 (以及局限)

`node tools/test_douyin.mjs` 在 Node 里用**模拟的 tt 对象 + @napi-rs/canvas** 直接运行打好包的 `build-douyin/`，没有任何 DOM：
