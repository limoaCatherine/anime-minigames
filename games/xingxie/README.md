# 星屑轮舞

- Windows 版：[xingxie-lunwu-windows.zip](https://github.com/limoaCatherine/anime-minigames/releases/download/xingxie-v1.3.2/xingxie-lunwu-windows.zip)
- 网页版：[xingxie-lunwu-web.zip](https://github.com/limoaCatherine/anime-minigames/releases/download/xingxie-v1.3.2/xingxie-lunwu-web.zip)

解压后双击打开：Windows 版是 `星屑轮舞\星屑轮舞.exe`，网页版是 `index.html`（用浏览器打开，不用联网）。
如果 Windows 提示「Windows 已保护你的电脑」，点「更多信息 → 仍要运行」。
