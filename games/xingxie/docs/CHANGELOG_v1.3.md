## 抖音小游戏
- 包内不含任何 ogg 文件或引用（iOS 不支持），BGM 来源在抖音构建中替换为只含 mp3 的版本；测试新增检查。
- BGM 无缝循环：mp3 编码器头尾会补 25~40ms 静音，loop=true 时接缝有空白。改为「循环 + 1 秒」文件 + 双实例在循环点 0.15s 等功率交叉淡化；波形分析确认循环点 ±0.5s 内无静音段。
- 上架说明补充：隐私协议和软著填开发者账号真实主体，「狸猫」只是出品名；流量主开通后填 ID 即可恢复广告。
