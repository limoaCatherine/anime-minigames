# 《星屑轮舞》抖音小游戏上架说明

出品：狸猫　｜　整理日期：2026-10-11（v1.3 更新）

> **先说清楚两件事：**
> 1. **「狸猫」只是出品名（游戏里和商店页显示的品牌）**，不是法律主体。隐私协议里的运营者名称、软著的著作权人，都必须填**你开发者账号认证的真实主体**（个人实名或公司全称），和开放平台后台的主体保持一致。
> 2. **流量主开通后，把激励视频广告位 ID 填进 `src/config/PlatformConfig.js` 并重新构建，广告就自动恢复**，不用改别的代码（见第 5 节）。

> 本说明根据抖音开放平台官方文档整理（链接附在每节末尾），**平台规则经常调整，一切以平台最新要求和后台实际页面为准**。
> 我们没有登录任何抖音账号，下面所有后台操作都需要你本人完成。

## 0. 目录里有什么

```
抖音小游戏/                 ← 用「抖音开发者工具」导入这个目录
  game.js                  主包代码 (玩法与网页版共用，平台层 src/core/platform/tt.js)
  game.json                竖屏 + 分包配置
  project.config.json      AppID (由构建脚本写入)
  assets/                  主包资源：头像、Boss、菜单背景、预渲染音效 (wav)
  sub_art/                 分包：角色半身立绘
  sub_bgm/                 分包：背景音乐 mp3
  sub_voice/               分包：角色语音 mp3
  上架资料/                本说明、隐私政策草案、商店文案、截图 (已在 packOptions.ignore 中排除，不会被上传)
```

包体（构建时自动统计，口径同开发者工具）：主包 ≈1.6 MB / 上限 4 MB；分包 立绘 ≈0.8 MB、音乐 ≈2.3 MB、语音 ≈3.1 MB（单个上限 20 MB）；总计 ≈7.8 MB / 上限 20 MB。
官方依据：使用分包时 主包 ≤ 4MB、单个分包 ≤ 20MB、整个小游戏 ≤ 20MB（开通虚拟支付后为 30MB）。
（[分包加载 · 概述](https://developer.open-douyin.com/docs/resource/zh-CN/mini-game/develop/guide/basic-function/subpackages/introduction)）

## 1. 注册开发者并完成主体认证

1. 打开 <https://developer.open-douyin.com/>，注册开放平台账号。
2. 完成主体认证：个人主体按页面提交实名信息；企业主体提交营业执照并完成对公验证。
3. **主体名称很关键**：软著的著作权人、（如有）版号的运营单位、隐私协议里的运营者，都要和这里认证的主体一致，不一致要额外提交盖章 / 签字的授权书。
4. **「狸猫」不是主体**：它只是出品名 / 品牌名，出现在游戏标题页、制作人员页和商店文案里。凡是要填「主体」「著作权人」「运营者」「开发者名称」的地方，一律填开发者账号的真实主体，**不要填「狸猫」**（除非你真的以「狸猫」为名注册了个体户 / 公司并完成认证）。

（[注册与入驻](https://developer.open-douyin.com/docs/resource/zh-CN/mini-game/guide/minigame/register)、[入驻开发者平台](https://developer.open-douyin.com/docs/resource/zh-CN/developer/join/join-into-developer-platform)）

## 2. 创建小游戏，拿到 AppID

1. 控制台 →「小游戏」→「创建小游戏」。
2. 开发引擎选「其他 / 原生 Canvas」类（本作没有使用 Cocos / Unity / Laya）；名称填 **星屑轮舞**（要和软著登记的软件名称一致）。
3. 创建后进入小游戏详情，「开发设置」里可以看到 **AppID**（tt 开头）。
4. 尽快在「总览 → 完善基础信息」填写：名称、图标、简介、详细介绍、软著、（版号）、适龄提示、自审自查报告确认、隐私政策等，提交后平台统一审核。

（[创建与信息完善](https://developer.open-douyin.com/docs/resource/zh-CN/mini-game/guide/minigame/improve-information)）

## 4. 激励视频：开通流量主、建广告位

1. 小游戏后台 →「商业化」→「流量主」申请开通，设置结算账户（须为小游戏所属主体的账户）。
2. 开通后在「流量主 → 广告管理」新建 **激励视频** 广告位，得到广告位 ID。
3. 准入条件以后台页面为准。开放平台「流量主」能力页写的是：需要**已上线**；个人主体还要求 DAU ≥ 50。也就是说**首个版本大概率要在没有真实广告的情况下先上线**（见第 7 节第 3 条）。

本作用到激励视频的地方（都是玩家主动点、看完才给奖励；没看完 / 拉取失败不发奖励、也不扣次数）：
- 死亡后「看广告复活」（每局 1 次）
- 升级三选一的「换一批」（免费次数用完后）
- 结算页「看广告 星屑翻倍」

**还没开通流量主（广告位 ID 留空）时**：上面的看广告按钮（换一批、结算翻倍）**全部不显示**，复活改为每局免费一次「再试一次」，不会弹任何占位广告——可以直接提审上线。
**流量主开通后**：在 `src/config/PlatformConfig.js` 填上广告位 ID → `npm run build:douyin` → 重新上传提审，三处激励视频自动恢复。

（[tt.createRewardedVideoAd](https://developer.open-douyin.com/docs/resource/zh-CN/mini-game/develop/api/javascript-api/ads/tt-create-rewarded-video-ad)、[流量主能力](https://developer.open-douyin.com/capacity-center-page/capacity-detail/7179893068693389370)）

## 5. 填配置（只有一个地方）

AppID 和激励视频广告位 ID **只在源码的这一个文件里填**：

```
src/config/PlatformConfig.js

export const PlatformConfig = {
  douyin: {
    appid: '',              ← 填 AppID，例如 'tt0123456789abcdef'
    rewardedAdUnitId: '',   ← 填激励视频广告位 ID
  },
};
```

填好后在项目根目录（`smallgame\星屑轮舞`）执行：

```
npm install            (第一次需要；只用到 esbuild，Node 18 以上)
npm run build:douyin   (重新生成 抖音小游戏/ 目录，并打印主包 / 分包大小)
```

- `rewardedAdUnitId` 留空：不显示任何看广告按钮（换一批 / 结算翻倍），复活改为每局免费一次「再试一次」，不弹占位广告。
- `rewardedAdUnitId` 填上并重新构建：激励视频（复活 / 换一批 / 翻倍）自动恢复，无需改其它代码。
- `appid` 留空：`project.config.json` 里写的是占位符 `YOUR_TT_APPID`，开发者工具导入时可以先选「测试号」预览（测试号不能上传）。
- 不要直接改 `抖音小游戏/project.config.json`，下次构建会被覆盖。

## 6. 用抖音开发者工具导入、预览、上传

1. 安装「抖音开发者工具」（开放平台文档站 → 开发者工具 → 下载）。
2. 登录你的开发者账号 →「导入项目」→ 选择 `smallgame\星屑轮舞\抖音小游戏` 目录 → AppID 用你在第 2 步拿到的（或先用测试号）。
3. 模拟器里先过一遍：启动 → 主菜单底部显示「正在下载立绘/音乐/语音 xx%（不影响开玩）」→ 开一局 → 结算。
4. **必须真机预览**：工具栏「预览」扫码。录屏（tt.getGameRecorderManager）在开发者工具里无法调试，只能真机测；侧边栏、激励视频也建议真机看一遍。真机重点看：
   - 刘海屏 / 胶囊按钮不挡 UI（画面会自动缩进安全区，上下留深色边）
   - 打完一局结算页出现「分享精彩录屏」，点了能进入发布页、带 #星屑轮舞 话题
   - 从抖音首页侧边栏「最近使用」进游戏 → 主菜单「侧边栏有礼」→ 领取 30 星屑币（每天一次）
   - 切后台再回来：战斗自动暂停、音乐停
5. 「上传」：填版本号（如 1.3.0）和更新日志。
6. 控制台「开发版本管理」→ 扫测试版体验 →「提交审核」，按要求上传 **3 张游戏内截图**（`上架资料/截图/` 里准备了 5 张 1080×1920 竖屏图）。
7. 首次上线审核含 QA 回归，官方说预计 1–3 个工作日。自 2026-04-20 起提审会自动覆盖所有接入抖音小游戏的合作 App，任一宿主端不通过都要改了重提。
8. 审核通过后「全量发布」或「灰度发布」。

（[版本提审指引](https://developer.open-douyin.com/docs/resource/zh-CN/mini-game/guide/minigame/examineguide)、[录屏](https://developer.open-douyin.com/docs/resource/zh-CN/mini-game/develop/api/javascript-api/media/screen-recording/tt-get-game-recorder-manager)、[侧边栏接入](https://developer.open-douyin.com/docs/resource/zh-CN/mini-game/develop/guide/open-ability/Introduction-for-tech)）

## 7. 容易被卡的地方

1. **分享按钮**：`tt.shareAppMessage` 的 videoPath 为空会直接打开拍摄器，审核不允许。本作只有拿到有效录屏后才显示「分享精彩录屏」，录屏不足 4 秒也不显示。
2. **侧边栏**：官方要求接入 `tt.navigateToScene`。本作在 `tt.checkScene` 返回支持时显示入口，点击后引导跳转侧边栏；从侧边栏回来才能领奖励。
3. **首个版本的广告**：流量主要求「已上线」，所以第一次提审时广告位 ID 多半还是空的。v1.3 起这种情况下游戏里**没有任何广告按钮或占位广告**（复活改为免费「再试一次」），可以直接提审。上线、开通流量主之后，填上广告位 ID 重新构建、提审即可恢复激励视频。
4. **VOICEVOX 署名**：语音规约要求在「应用的介绍页」也能找到署名，`商店文案.md` 的详细介绍里已经带上「VOICEVOX:角色名」，请保留。
5. **名称一致**：小游戏名称、软著软件名称、游戏内标题都是「星屑轮舞」。
6. **隐私政策**：后台有小游戏自有的隐私政策页，名称和主体自动带出；`隐私政策_草案.md` 可作为补充内容参考，**需要法务或你本人审核后再用**。草案里的【主体名称】【联系方式】要换成**开发者账号的真实主体**和真实联系方式，不要写「狸猫」。
7. **软著**：申请软著时，著作权人填**真实主体**（与开发者账号一致），软件名称填「星屑轮舞」（可带「游戏软件」后缀）。「狸猫」作为出品名可以出现在软件界面里，但不能当作著作权人。
8. **音频格式**：抖音 iOS 端不支持 ogg。抖音工程里只有 mp3（语音 / 音乐）和 wav（短音效），自动测试会检查没有任何 ogg 文件或引用。背景音乐的循环接缝做了无缝处理（mp3 头尾编码静音 → 双实例交叉淡化），真机听一下循环点即可。
