# 语音去沙哑（v1.3.2）

用户试听反馈「语音有点沙哑」。用 `tools/voice_quality.py` 对全部 137 条语音做客观测量，并在 v1.1 的生成流程上逐项开关做消融，定位来源后重新生成。

## 原因

1. **声线选择（主因）**：元気（星野光的兴奋 / 喝声台词）、ささやき、絶望と敗北、怒り 等风格本身气声重。按风格统计谐噪比：ささやき 1.1 dB、絶望と敗北 3.1 dB、怒り 5.4 dB、元気 6.0 dB，而 ノーマル 10.5 dB、あまあま 11.5 dB；元気 的 4-10 kHz 能量占比 −11.7 dB，比 ノーマル 高约 9 dB（听感就是「沙」）。最差 10 条里 7 条是星野光的 元気 / 喝声台词。
2. **手调音高伪影**：v1.1 逐音拍加随机抖动、放大起伏 (×1.15~1.4)、随机拉伸元音时长，加上 intonationScale 1.4~1.75、语速最高 1.38 倍，声码器出伪影。消融：只把语速 / 抑扬统一到 1.18 / 1.25，最差 13 条 HNR 4.3→5.4 dB；再去掉逐音拍整形 →6.9 dB。语速与 HNR 相关系数 −0.34。
3. **后期叠加的噪声**：「气声层」(跟随包络的高通噪声) + 句首吸气 / 句间换气 / 句尾叹气样本，抬高句内 4-10 kHz 噪声底（消融：去掉后最差 13 条噪声底 −60.9→−64.8 dBFS）；10 kHz 高频提升 +1.5 dB 和双抽头房间混响把这些噪声和齿音再放大一点。
4. **码率**：96 kbps。这项不是沙哑主因（削波 0、true peak 最高 −1.8 dBTP，都合格），但顺手提到 160 kbps。
5. 另有超短感叹词（きゃっ / ひゃっ）几乎全是清音，被拉到 −20 LUFS 时听起来是一团噪声，其中 kanon_hurt_1 增益封顶后只有 −33.9 LUFS。

## 修复

- 声线：所有气声 / 沙哑类风格换成该声优干净的声线（ノーマル / あまあま / ツンツン / セクシー / ぶりっ子 / クイーン；つよつよ 只留桃濑萌的喝声 / 生气 / 得意，おどおど 只留稻荷铃音的害羞）。声优没变，配音署名不变。
- 语调：语速统一 1.13~1.22（生成器里强制夹住），intonationScale ≤ 1.25，短语内起伏 ≤ ×1.05，去掉逐音拍随机抖动和元音时长随机化，句尾形状保留但幅度减半。
- 噪声：去掉气声层；去掉句首吸气、句尾叹气；换气只留在 ≥2 句且较长的台词句间，电平为峰值的 2.5%。
- 后期：去掉高频提升和房间混响；低切 80 Hz、11.5 kHz 低通（引擎原生 24 kHz，上面只剩重采样残留）、3.5 kHz −1.5 dB、轻度 de-ess；线性增益对齐 −20 LUFS → 限幅（−2.5 dBFS 起，留 headroom）→ 160 kbps / 44.1 kHz mp3；编码后复测，不达标自动修正再编。
- 超短感叹词的合成文本改成 きゃあっ / ひゃあっ（字幕不变；月见雪乃的 ひゃっ 测下来原样更干净，保持不变）。
- 播放端不变：语音 −20 LUFS、说话时 BGM 压到 ×0.55。
