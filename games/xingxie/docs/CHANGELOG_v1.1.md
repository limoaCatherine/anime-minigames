# 《星屑轮舞》 v1.1 更新说明

## 胜利条件 / Boss
- 胜利必须击败梦魇女王诺克丝。5:00 时她还活着 → 「黎明前最后一搏」：刷怪 ×0.35，晨光增伤 ×1.2 起、每秒 +0.02，诺克丝每秒被灼烧 0.5% 最大 HP（不会无限拖）。HUD 计时变成闪烁的「黎明前最后一搏」+「晨光增伤 ×n」。
- 数羊王 75 秒没打完会打着哈欠溜走；诺克丝登场时羊王先退场（修复：以前羊王会冻结残留在场上、没有血条）。
- Boss 控制抗性：不吃冻结 / 眩晕 / 击退，减速最多 30%（精英最多 50%）；被甩出 620px 会瞬移回屏幕边；屏幕外有方向箭头。
