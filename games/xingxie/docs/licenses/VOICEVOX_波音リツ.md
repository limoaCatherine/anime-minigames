## 三、本作的遵守方式

- 游戏内「设置 → 制作人员」页面逐条标注「VOICEVOX:波音リツ」，网页版 / 桌面版 / 抖音小游戏版相同。
- 抖音小游戏的简介（商店页）也附上 VOICEVOX 署名（规约要求应用类在介绍页可找到署名）。
- 不用于政治 / 宗教 / 公序良俗相违的内容，不冒充官方，不用生成音声训练模型。
- 另须遵守 VOICEVOX 软件本身的利用规约，见 VOICEVOX_ソフトウェア利用規約.md。
