## 一、自查结论（对照官方《小游戏隐私合规开发指南》表 1 的标准 API）

本游戏代码**没有调用**表 1 中任何涉及用户个人信息的接口：
- 不调用 wx.getUserInfo / getUserProfile / createUserInfoButton（不读昵称头像）
- 不调用定位、微信运动、相册 / 文件选择、麦克风、摄像头、蓝牙、传感器、剪贴板
- 不使用开放数据域、好友关系链（wx.getFriendCloudStorage 等）、游戏圈数据
- 没有自定义表单、没有账号系统、没有任何网络请求（wx.request 等均未使用）

只用到的能力：画布、触摸、本地存储（wx.setStorageSync 存星屑币 / 天赋 / 设置 / 战绩）、音频、分包加载、转发（wx.shareAppMessage / onShareAppMessage / onShareTimeline）、激励视频广告（wx.createRewardedVideoAd，开通流量主后才启用）。

→ 按官方指南步骤二：**「如果自查没有处理任何用户个人信息，只需前往『MP设置-服务内容声明-用户隐私保护指引-确认承诺未处理用户任何信息』，无需关注后续流程。」**

> 注意：激励视频广告由微信广告平台提供，广告侧的数据处理适用微信 / 腾讯广告的规则；以后若新增上面表 1 里的任何接口（例如排行榜要用好友关系链），必须先回到该页面「更新」并勾选对应信息类型，否则接口会报 112 / 1025 错误。
