## 游戏内容介绍（提审「游戏内容介绍」/ 小游戏备案的玩法说明可参考）

夜里有一群梦魇想钻进大家的梦里，守夜的魔法少女只有你。

单手拖动走位，攻击全是自动的。捡星星升级，三选一挑技能，凑齐被动开宝箱让武器进化。怪越刷越多，五分钟时天会亮——前提是你还站着，而且打倒了梦魇女王诺克丝。

· 一局五分钟，等车、排队刚好一局
· 6 位魔法少女，各有自己的初始武器和专属被动
· 9 种武器，进化后形态全变，满屏割草很解压
· 打不过就攒星屑币点天赋，下一局更硬
· 普通和噩梦两档难度，通关一次开放噩梦
· 打完一局可以一键转发给好友

玩法要点（备案 / 审核写「场景、玩法、功能」时可直接用）：
1. 场景：竖屏单场景战斗（夜空下的梦境平原），主菜单 / 选角 / 天赋 / 制作人员 / 结算五个界面。
2. 玩法：单指拖动摇杆移动，武器自动攻击；击败怪物掉落经验星，升级时三选一获得武器或被动；开宝箱可使武器进化；坚持 5 分钟并击败最终 Boss 即胜利。
3. 功能：局外用星屑币升级天赋、解锁角色；本地存档（wx.setStorageSync）；转发给好友 / 分享到朋友圈；激励视频（可选：看完复活一次 / 刷新三选一 / 结算星屑翻倍，未开通流量主时不显示）。
4. 无内购、无虚拟支付、无抽奖、无排行榜、无聊天 / 陌生人社交、无账号登录、不联网上传任何数据。
